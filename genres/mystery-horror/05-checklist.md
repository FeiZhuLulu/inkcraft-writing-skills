# 悬疑惊悚 · 自检

写完后逐条勾选。这不是死板评分，也不是自动退稿门槛。有一条不成立，立刻回到对应写法修改，不要靠堆砌惊悚形容词补救。

## 结构与场面

- [ ] 核心怪事是否由两组不可同时为真的硬事实构成（回到「异常起问开篇」）
- [ ] 关键线索是否在最终推论前已在现场合理亮相并承担场景功能（回到「公平线索投放」）
- [ ] 误导是否由真实线索支撑且在真相下依然成立（回到「公平误导」）
- [ ] 假设修正是否由无法容纳的新证据推动，而非主角凭空灵光一闪（回到「假设修正」）
- [ ] 揭秘后是否只恢复眼前平衡并真实保留深层恐惧余波（回到「揭示与恢复」）
- [ ] 规则测试是否通过单变量控制得出可证伪的硬规则（回到「规则测试」）
- [ ] 章末是否留下下一步必须去核查的明确地点、证人或档案

## 成文

- [ ] 解释是否发生在客观异常之后，而不是打断正在发生的惊悚体验
- [ ] 对白是否保留信息差、试探与隐瞒，而不是直白总结案情
- [ ] 句段是否随恐惧逼近与推理勘验发生长短切换
- [ ] 叙述距离是否严格限制在当前调查者的可知范围之内


## 本场计数

按本章实际使用的那一种写法勾选。数字与 `03-methods.md` 该节一致，不是评分。

### 异常起问开篇

- [ ] 不可同时为真的事实至少 2
- [ ] 验证行动至少 1
- [ ] 必须留下可取证的问题

### 公平线索投放

- [ ] 揭示前可见的线索至少 1
- [ ] 同时承担场景行动的线索至少 1

### 公平误导

- [ ] 在真相下仍成立的线索至少 2
- [ ] 可见矛盾至少 1
- [ ] 揭示时才追加的决定性事实为 0（不要出现）

### 假设修正

- [ ] 被新证据推翻的旧解释至少 1
- [ ] 因新信息改变的下一步至少 1

### 揭示与恢复

- [ ] 揭示后的新行动至少 1
- [ ] 保留的余患至少 1
- [ ] 不要立刻完全恢复

### 规则测试

- [ ] 每次测试只改变 1 个关键变量
- [ ] 被结果排除的解释至少 1

## 快速回退

勾不上「公平线索」：在第二章现场补一个看似普通但与作案手法密切相关的物理物件。  
勾不上「有下一步」：把章末的恐怖感叹改成明天清晨必须赶去的下一家档案馆或停尸房。  
勾不上「有误导」：给最明显的嫌疑人设计一份真实成立但充满巧合的不在场证明。
