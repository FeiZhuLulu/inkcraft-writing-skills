# 悬疑惊悚写作

## 触发条件

项目或用户任务是悬疑、惊悚、灵异、克苏鲁，或明确要求按悬疑惊悚方法写、改、审章节。

## 执行步骤

1. 先读项目设定、线索账本、大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要随意更改底层真相。
2. 判断当前任务：开书设计、前三章、调查推进、谜题反转，还是审阅。
3. 开书：确认核心谜题与恐惧源、认知优势与盲点、异常规则、线索账本、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章并置不可同时成立的事实，第2章提出验证方案与最低生存规则，第3章执行验证并让异常升级。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「异常起问开篇 / 公平线索投放 / 公平误导 / 假设修正 / 揭示与恢复 / 规则测试」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见」执行。
6. 成文：句长约 20–35 字，段长约 25–45 字，对白大约两成上下。先投放未闭合异常再推导。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 线索在结论得出前已在现场可见
- 异常形成可复核、可证伪的硬规则
- 误导具有合理性但保留破绽
- 章末留下可验证的下一步调查动作

## 硬约束

- 读者承诺：让读者与主角共享可验证线索，在解释不断失效时仍有机会提前接近真相
- 不要瞒匿关键事实搞机械降神式的突兀反转
- 不要用廉价做梦或精神错乱敷衍超常谜题
- 区间不是合格线；提前剧透或解释封闭比数字偏离更严重
