# 悬疑惊悚写作

## 触发条件

项目或用户任务是悬疑、惊悚、灵异、克苏鲁，或明确要求按悬疑方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认核心谜题、认知盲点、异常规则、线索可见范围、前三章验证行动。缺一项就先问作者。
4. 开篇：并置矛盾事实，提出验证，执行验证并让异常升级。
5. 章内：按本章功能选用「公平线索 / 公平误导 / 假设修正 / 规则测试 / 揭示与恢复」。
6. 成文：句长约 20–35 字，段长约 25–45 字，对白大约两成上下。线索先落地，解释后置。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 读者能复述当前问题
- 线索在揭示前可见
- 揭示重释旧证据，不追加唯一决定性事实
- 章末有下一次取证

## 硬约束

- 读者承诺：与主角共享可验证线索
- 不要靠事后补写决定性事实
- 不要让角色替读者总结谜底
- 区间不是合格线；线索不可见比数字偏离更严重
