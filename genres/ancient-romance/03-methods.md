# 古言 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖试探、博弈、破防、开篇、礼数、高潮，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、如何检查、失败了怎么改。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 身份试探

适用：开篇破局、初次拜谒长辈、宴席试探、初见权贵、暗中确立后宅尊卑等级。

上场先定：表面遵循的端庄礼数与坐席次序；通过茶盏、服饰、称谓或微小礼节暴露出的权力高下；女主以退为进改写关系账本的选择。

步骤：

1. 从极具古代生活质感的礼仪细节切入：给长辈敬早茶、在花厅按宗族齿序就座、丫鬟捧上不同成色的布料。
2. 反派长辈或姊妹利用称谓、座次或冷茶故意发难，进行身份层面的无声试探与下马威。
3. 女主不急不怒，依足礼法规矩优雅回应，在规矩框架内点破对方的僭越或失德之处。
4. 长辈长久注视后重新定夺座次或赏赐，后宅权力的微观天平发生实质位移。

纸上必须看见：一道森严的座次称谓规矩、一次用礼数包裹的试探发难、一次端庄精准的反戈一击、一处被纠正的礼节特权。

检查：身份信号是否具有可视化的物理载体（茶盏水温、座位高低、帕子花纹）；是否避免了毫无尊卑意识的泼妇对骂。

失败：女主面对主母刁难，直接冲上去把主母的茶杯掀翻大骂，把世家千金写成了疯批悍妇。改法：女主跪在蒲团上，轻声指出主母今日赏下的这碗茶用的是贡品雀舌，按制唯有一品诰命夫人方可享用，继母若私用恐招御史弹劾，吓得继母当场撤下茶盏。

教学：侯府寿堂之上，长房大夫人端坐主位，故意将最靠近风口、摆着粗瓷劣茶的下首小圆凳留给刚被接回府的嫡女主角。众贵女掩唇冷笑。主角身着素净月白云锦，步履盈盈上前，双膝跪在红毡正中，依大内宫规行了无可挑剔的三跪九叩大礼，抬眸轻柔道：「大夫人安好。母亲生前常教导女儿，侯府乃世袭彻侯，堂上陈设皆依宗人府旧制。今日大夫人将三品正妻方可坐的黄花梨正座设在寿堂，却让掌管太夫人赏赐金印的嫡长女坐风口，不知是哪位管事妈妈排的座次，若是传到宗正寺耳中，恐伤了侯爷前程。」老太夫人闻言面色一沉，当场下令将管事妈妈拉出去打二十大板，并将主角迎至自己身旁软榻同坐。

## 家族资源博弈

适用：争夺中馈管家权、清查库房亏空、夺回生母嫁妆、分发月例银子、处置族中田产。

上场先定：被侵占或争夺的核心家族资产清册（庄子地契、铺子账本、库房对牌）；双方各自搬出的靠山与宗法依据；反击后留下的实质产业移交与后续追责。

步骤：

1. 亮出清晰量化的家族资产账本与当前被克扣挪用的铁证（生母留下的十万两嫁妆被继母私自变卖了三座绸缎庄）。
2. 女主在宗族族老或老太爷面前，以宗法家规与《大明律/朝廷律例》为武器，公开申请查账审计。
3. 掌权主母动用宗族孝道、甚至伪造借据进行疯狂阻挠与反咬。
4. 女主甩出事先暗中搜集到的当铺绝密存根或人证，一击毙命，当场收回资产钥匙与对牌。

纸上必须看见：一份详实的嫁妆/中馈清册、一次激烈的公堂/宗祠对质、一枚沉甸甸交接的铜铸对牌钥匙。

检查：争夺的资源是否具有具体的经济与政治价值；是否展现了古代内宅经济的运作逻辑。

失败：女主张口就要回了几百万两白银，主母乖乖双手奉上，没有任何博弈过程。改法：写出女主带着生母陪嫁的老账房，连夜用三把算盘核算出三万两账目漏洞，逼得继母不得不割让两处当铺抵债。

教学：宗祠花厅内，主角将生母当年的红木嫁妆单子重重摊在老太爷面前。继母哭天抢地称当年为了给府里填补亏空，嫁妆早已折变干净。主角神色淡然，拍了拍手，京城最大通汇钱庄的大朝奉大步走入花厅，呈上三张汇票底根：「大夫人说折变干净了，那请问上个月大夫人名下的娘家兄弟，为何凭着我母亲嫁妆里的‘双凤衔珠金冠’，在通汇钱庄抵押了整整八千两白银，转头买下了城东的一座五进大宅？」铁证如山，老太爷气得将茶盏狠狠砸在继母脚下，当场夺了继母腰间的库房对牌钥匙，亲手交到主角手中，勒令由主角即日起全权协理全府中馈。

## 情感边界位移

适用：男女主深夜独处、私下赠送信物、屏风后避嫌、危难中并肩、情感防线发生实质跃迁。

上场先定：开场时恪守的男女大防与冰冷社交礼数；推动越界的突发意外或危机契机；越界后留下的专属信物或秘密接触特权。

步骤：

1. 在场景开头明确写出封建礼教对男女大防的严苛限制（隔着三层屏风、外间有大批丫鬟婆子值守）。
2. 用一场突发的生死危机或暗杀搜索（刺客搜查闺房、暴雨中马车陷泥、男主中箭重伤潜入）强行撕破物理防线。
3. 男女主在咫尺之间近距离接触，动作隐秘而克制，眼神在黑暗中完成无声的确认与交锋。
4. 危机过去后，男主留下一枚私印或贴身玉佩，女主默许收下，两人确立了超越普通名分的深层隐秘同盟。

纸上必须看见：一道被跨越的闺阁屏风、一次屏息凝神的极近距离肢体躲避、一件藏进袖口的秘密信物。

检查：情感的推进是否始终带着古代男女大防的禁忌感与克制张力；下一章是否坚决保留了该特权。

失败：男主大白天直接踹开未出阁女子的闺房强行搂抱，周围丫鬟太监全当看不见。改法：男主在夜深人静时踏着月色无声落在窗棂外，隔着一层薄如蝉翼的窗纱，将一瓶解毒生肌膏放在窗台上。

教学：暴雨倾盆的寒夜，身受箭伤的权臣男主翻窗躲入主角的西厢暖阁，鲜血滴在白狐地毯上。门外，锦衣卫的砸门声震天响。主角没有尖叫，迅速拉开拔步床的锦帐，将浑身湿透血腥的男主推进床底暗格，自己则散开青丝，披上寝衣倚在床头。锦衣卫首领踹门而入，主角冷声呵斥其擅闯未出阁贵女寝居之罪，以侯府威严逼退追兵。追兵退去，男主自暗格中翻出，一手按住流血的肩头，深邃的黑眸紧紧盯着她微乱的青丝，从腰间解下一枚刻有麒麟暗纹的玄铁私印塞进她微凉的掌心：「持此印，京城九门与玄甲卫，随时听你调遣。」原本冰冷的公事同盟，在这一夜彻底崩塌为生死相托。

## 家内事件开篇

适用：开书第一章、退婚发难、落水苏醒、中元节还魂、以家庭微观事件引爆全局矛盾。

上场先定：主角苏醒时置身于迫在眉睫的家法处决或毁名死线；对方利用的宗法名义；主角抓出的第一个程序破绽。

步骤：

1. 一开篇就将女主置于极具侮辱与毁灭性的家内审判现场（柴房受刑、祠堂罚跪、被逼吞下绝育哑药）。
2. 反派搬出冠冕堂皇的宗法礼教（如「不遵孝道、克死生母、与小厮私通」），试图在短时间内将女主彻底定罪并处置。
3. 女主在绝境中抬起头，眼神冷静如刀，直接揪出对方在行刑程序、证人资格或时间证据上的致命漏洞。
4. 迫使执法长辈动作停滞，成功为自己赢下三日自证清白的生死缓冲期。

纸上必须看见：一个冰冷残忍的受刑现场、一份强加的莫须有罪名、一次冷静绝伦的程序反制。

检查：开篇是否在极短时间内立住女主隐忍、清醒、绝不坐以待毙的大女主心性。

失败：第一章写了三千字女主在床上感叹穿越，然后丫鬟进来梳头梳了半个时辰。改法：第一句直接写「粗使婆子那只满是老茧的脏手，正端着一碗滚烫的落子汤，狠狠往女主嘴里灌」。

教学：祠堂冰冷的青砖地上，刚从冰水里捞上来的主角被两条粗麻绳死死捆在长凳上。继母手持沾了盐水的皮鞭，厉声宣告其在后山私会马夫、败坏门风，当处家法杖毙。眼看家丁举起齐眉棍，主角猛然抬头，清冽的声音响彻宗祠：「且慢！按《大理寺通典》，凡告内宅妇人通奸者，须奸夫指认、私信存底、守宫砂验明三者皆备方可动刑！今夜马夫何在？私信何在？大夫人不经老太爷过目，连夜动用私刑杖毙原配嫡女，敢问大夫人，您是急着维护门风，还是急着杀人灭口，好让您的庶女名正言顺替我去赴东宫的大选？！」执刑家丁吓得长棍脱手，老太爷的怒喝声已自祠堂门外滚滚传来。

## 礼数潜台词

适用：奉茶请安、花厅宴饮、宫廷赐宴、官眷应酬、表面温良恭俭让背后的刀光剑影。

上场先定：对话表面讨论的极为日常端庄的闺阁话题（刺绣、品香、节气养生、求神拜佛）；两人心底真正较劲的生死政治筹码；出卖真实杀机的微小礼仪动作。

步骤：

1. 台词维持在极度端庄、文雅甚至带着长辈关怀的表面礼节上。
2. 将政治站队、退婚要挟、下毒警告等致命杀机，完全编织进茶名、花样、诗词或佛经的潜台词隐喻中。
3. 双方在优雅的奉茶、低头、扶鬓等动作中，进行高密度的心理攻防与筹码试探。
4. 对方完全听懂了潜台词中的警告，被迫改变接下来的针对策略。

纸上必须看见：端庄典雅的世家对白、一处带有隐喻的道具（一碗冷茶、一朵带刺的绢花）、一次神色骤变的动作停顿。

检查：删掉人物动作后，对白是否表面温和无害但细思极恐；潜台词是否能被读者精准领会。

失败：贵妇们在宴会上像泼妇一样互骂「你这个贱人你不得好死」。改法：贵妇微笑着夹起一块苦瓜放进对方碗里，慢悠悠说了一句「妹妹这几日肝火旺，多吃点苦，免得日后在冷宫里吃不惯苦食」。

教学：长公主的赏花宴上，贵妃娘娘屏退左右，亲手给主角斟了一杯冷掉的碧螺春，笑吟吟道：「林姑娘这双手生得极巧，听说前几日给东宫绣了一副江山万里图，只是这江南的雨水多，丝线容易发霉，走错了针脚，可是要扎烂整幅缎子的。」主角双手接过冷茶，垂眸轻抿一口，神色温婉如玉：「多谢娘娘赐茶。臣女愚钝，针脚虽粗，但用的却是前朝传下来的金刚锁边针，江南的雨水再大，也只能洗去缎面上的浮尘。倒是娘娘宫里的牡丹开得太盛，花枝太沉，若是压断了主干，怕是连今年的秋霜都熬不过去呢。」贵妃手上的金镶玉护甲猛然在紫檀桌面上划出一道白痕，笑容瞬间僵死在脸上。

## 局部胜利后的关系选择

适用：大宴翻盘、退婚打脸、夺回爵位、皇帝赐婚、阶段性大高潮。

上场先定：本场彻底兑现的后宅胜利与名分提升；反派遭受的实质性惩罚；男主在胜利背后抛出的更高政治与情感抉择。

步骤：

1. 实打实兑现一项后宅或朝堂的巨大胜利成果（继母被夺权幽禁、庶妹被逐出宗祠、皇帝下旨赐封郡主）。
2. 在全族敬畏、宾客逢迎的巅峰时刻，男主在暗处与女主相见，揭开胜利背后的更大危局（此案已惊动当朝帝王，朝廷党争即将借此洗牌）。
3. 男主递上婚姻盟约或政治庇护的选择权，女主清醒权衡，做出带代价的全新关系绑定。
4. 章末确立两人正式的未婚夫妻或政治同盟关系，开启下一卷朝堂与深宫的征战。

纸上必须看见：一份盖有官印的赏赐/判决文书、满堂宾客的敬畏目光、男主递过来的婚书或玉佩、一道通往更高名利场的大门。

检查：局部成果是否真实彻底地交给了女主；新选择是否将情感与更大的家国权谋结合。

失败：女主赢了之后就原地结婚完结，完全丧失了后续的大女主成长线。改法：皇帝赐婚的圣旨刚下，男主便低声告诉她：边关即将开战，这封婚书不仅是庇护，更是一张随时可能成为寡妇的生死契约。

教学：金銮殿前，大太监手捧明黄圣旨高声宣读：「侯府嫡女林澈，端庄贤淑，屡破奇案有功，特赐封为正一品安国郡主，加封邑三千户！」满朝文武与侯府全族齐刷刷跪倒在主角脚下，继母与庶妹面如死灰。退朝后的御花园回廊下，男主负手立在漫天飞雪中，将一份红绸包裹的庚帖递到她面前：「安国郡主，如今满朝都知道你是本王的人。但这封婚书签下去，明日早朝，东宫与三位藩王便会视你为头号死敌。你若后悔，现在便可撕了它，去封邑安稳过一生。」主角迎着风雪微微一笑，接过庚帖塞入袖中，目光清亮而决绝：「王爷，我林澈要的从不是偏安一隅。这泼天的富贵与杀局，我陪你赌了。」
