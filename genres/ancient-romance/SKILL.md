# 古言写作

## 触发条件

项目或用户任务是古言、宅斗、穿书、宫斗，或明确要求按古言方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物宗族谱系、礼制大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要随意打破古代宗法礼制。
2. 判断当前任务：开书设计、前三章、内宅博弈、情感破防，还是审阅。
3. 开书：确认古言卖点、初始闺阁死局、宗法礼制硬约束、家族利益网络、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章家内日常事务中的身份试探，第2章称谓资源与家族权力形成阻力，第3章边界位移与持续接触通道。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「身份试探 / 家族资源博弈 / 情感边界位移 / 家内事件开篇 / 礼数潜台词 / 局部胜利后的关系选择」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见 → 本场计数」执行。
6. 成文：句长约 25–40 字，段长约 40–55 字，对白大约一成上下。用称谓、座次与礼数承载权力，先写行为后果再推情感。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 礼数规矩与宗法制度成为坚硬的博弈武器
- 每次反击切实夺回对牌、嫁妆或名分等实质资源
- 对白保持端庄礼貌表层与冰冷潜台词杀机
- 章末留下下次交锋的明确宴席或借口

## 硬约束

- 读者承诺：用身份、家族资源、礼数和情感边界推进关系，让每次反击改变关系账本而不是只赢口头
- 不要让女主脱离宗法大防公然像泼妇一样撒泼打滚
- 不要让男主毫无政治与家族利益权衡地无脑倒贴
- 区间不是合格线；心理直白解说打断闺阁暗流比数字偏离更严重

本场计数按所选写法执行，数字只来自该写法的量化控制：

- 身份试探：身份信号至少 2；关系账本变化至少 1。
- 家族资源博弈：资源分配者至少 2；是否使用的选择至少 1；继承到下一局的状态至少 1。
- 情感边界位移：可观察的边界变化至少 1；在后续仍有效的权限变化至少 1。
- 家内事件开篇：具有身份后果的家内事务至少 1；持续关系通道至少 1。
- 礼数潜台词：台词必须维持礼貌表层；称呼、动作或沉默暴露的真实目标至少 1。
- 局部胜利后的关系选择：局部结果至少 1；下一次接触选择至少 1。
