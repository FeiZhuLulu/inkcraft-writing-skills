# 古言写作

## 触发条件

项目或用户任务是古言、宅斗、穿书、宫斗，或明确要求按古言方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认身份规则、家族资源、礼数通道、情感边界。缺一项就先问作者。
4. 开篇：家内身份试探，权力阻力，边界位移与持续接触。
5. 章内：按本章功能选用「身份试探 / 家族博弈 / 情感边界 / 礼数潜台词 / 关系选择」。
6. 成文：句长约 25–40 字，段长约 40–55 字，对白大约一成上下。礼数表层，称谓和沉默承潜台词。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 身份信号可观察
- 反击改变账本
- 潜台词靠动作
- 章末有下一次接触选择

## 硬约束

- 读者承诺：身份、资源和边界推进关系
- 不要贴现代心理标签
- 不要把另一方心声写成已知事实
- 区间不是合格线
