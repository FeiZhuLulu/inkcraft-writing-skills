# 仙侠写作

## 触发条件

项目或用户任务是仙侠、修真、修仙、宗门，或明确要求按仙侠方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、境界大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要编完整境界表。
2. 判断当前任务：开书设计、前三章、修炼突破、宗门争夺，还是审阅。
3. 开书：确认修仙卖点、凡俗初始压力、道法媒介与代价、宗门秩序、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章可感知的凡俗压力与选择，第2章修行事实或遗物产生可验证后果，第3章能力门槛与新债务形成行动问题。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「修行阈值与代价 / 宗门资源选择 / 凡俗困局抬升仙侠尺度 / 道法后果先行 / 试炼—反馈—再试炼 / 突破伴随新债务」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见 → 本场计数」执行。
6. 成文：句长约 25–40 字，段长约 35–45 字，对白大约两成上下。先写道法后果再补规则。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 道法通过具体的物理与生理后果被看见
- 资源稀缺且取舍改变后续权限与关系
- 突破必然伴随损耗、反噬或新因果债务
- 章末有下一步必须执行的修行或避祸动作

## 硬约束

- 读者承诺：让人物在修行资源、道统关系与因果边界中争取力量和位置；每次突破都改变下一步选择并留下代价
- 不要开篇大段灌输三界九洲大百科与完整境界表
- 不要让灵石丹药无限刷新、毫无修真界资源压迫感
- 区间不是合格线；口诀与境界解释打断斗法比数字偏离更严重

本场计数按所选写法执行，数字只来自该写法的量化控制：

- 修行阈值与代价：可观察反馈至少 1；代价或边界至少 1。
- 宗门资源选择：资源选项至少 2；状态变化至少 1。
- 凡俗困局抬升仙侠尺度：修行事实最晚第 3 章交付；必须留下可行动钩子。
- 道法后果先行：必须先写可观察后果，再补解释；规则改变的下一步选择至少 1。
- 试炼—反馈—再试炼：试炼步骤至少 2；下一阈值至少 1。
- 突破伴随新债务：兑现的修行回报至少 1；新债务至少 1。
