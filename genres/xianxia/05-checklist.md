# 仙侠 · 自检

写完后逐条勾选。这不是死板评分，也不是自动退稿门槛。有一条不成立，立刻回到对应写法修改，不要靠堆砌仙风道骨的华丽形容词补救。

## 结构与场面

- [ ] 修行能力是否通过具体的物理/生理反馈看见，而非空泛境界名（回到「修行阈值与代价」）
- [ ] 宗门资源是否稀缺且取舍改变了后续权限与人情（回到「宗门资源选择」）
- [ ] 前三章是否从凡俗压力切入并交付了可验证的修行事实（回到「凡俗困局抬升仙侠尺度」）
- [ ] 道法规则是否通过真实的身体或环境后果证明，而非背诵口诀（回到「道法后果先行」）
- [ ] 试炼失败是否提供了关键新情报并指引下一步尝试（回到「试炼—反馈—再试炼」）
- [ ] 突破回报是否必然伴随追杀、反噬或新的因果债务（回到「突破伴随新债务」）
- [ ] 章末是否留下下一步必须去执行的明确修行或逃生目标

## 成文

- [ ] 解释是否发生在道法破坏之后，而不是打断正在出鞘的飞剑
- [ ] 对白是否推动利益索取、师门博弈或神魂誓约，而不是修仙套话
- [ ] 句段是否在雷霆搏杀与参悟阵法中实现长短切换
- [ ] 叙述距离是否严格限制在当前修士的神识感知范围之内

## 快速回退

勾不上「看见道法」：删掉半页吐纳描写，加一次飞剑斩断护栏或一次经脉反噬咳血。  
勾不上「有下一步」：把章末望天感叹改成天亮前必须赶往的黑市坊市或巡山使者堵门的脚步声。  
勾不上「有选择」：把两全其美的赏赐砍掉一半，写清主角得罪了哪位执法长老。
