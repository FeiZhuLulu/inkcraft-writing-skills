# 都市超凡写作

## 触发条件

项目或用户任务是都市超凡、都市异能、都市高武，或明确要求按都市超凡方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认都市锚点、异常规则、组织或校园通道、暴露与责任。缺一项就先问作者。
4. 开篇：日常目标，异常侵入，能力边界或责任压力。
5. 章内：按本章功能选用「日常到异常 / 制度化超凡 / 能力代价 / 小队分工 / 异常回收」。
6. 成文：句长约 20–30 字，段长约 25–35 字，对白大约一成上下。异常用制度或身体反应落地。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 异常改变行动
- 能力带代价
- 日常压力仍在
- 章末有可执行责任

## 硬约束

- 读者承诺：都市制度与超凡规则并置
- 不要一段话堆完设定
- 不要把未知写成全知
- 区间不是合格线
