# 都市超凡写作

## 触发条件

项目或用户任务是都市超凡、都市异能、都市高武，或明确要求按都市超凡方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物小传、都市背景大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要随意架空现实都市。
2. 判断当前任务：开书设计、前三章、能力测试、小队作战，还是审阅。
3. 开书：确认超凡卖点、都市初始困境、能力代价与边界、组织制度、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章都市日常目标与异常侵入，第2章机构测试或组织接触，第3章能力边界、暴露风险与新责任。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「日常到异常切换 / 制度化超凡 / 校园/机构开篇 / 能力—代价—选择 / 都市小队分工 / 异常回收与新责任」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见 → 本场计数」执行。
6. 成文：句长约 20–30 字，段长约 25–35 字，对白大约一成上下。现实口语与超凡动作分工，先写后果再补解释。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 现实都市生活与超凡规则产生强烈碰撞
- 异能使用带来明确的身体代价或暴露风险
- 组织制度切实改变人物行动权限与任务
- 章末留下必须去执行的下一项都市任务

## 硬约束

- 读者承诺：把熟悉的都市制度、校园或组织与超凡规则并置，让能力提升同时扩大暴露、债务或责任
- 不要开篇脱离现实都市直接写架空神魔大战
- 不要让异能毫无物理反噬与监管成本地随意滥用
- 区间不是合格线；大段设定解说打断现场调查比数字偏离更严重

本场计数按所选写法执行，数字只来自该写法的量化控制：

- 日常到异常切换：熟悉的都市目标至少 1；打破常识的异常至少 1。
- 制度化超凡：组织流程或测试步骤至少 2；权限限制至少 1。
- 校园/机构开篇：日常压力至少 1；身份暴露或责任压力至少 1。
- 能力—代价—选择：能力效果至少 1；使用代价至少 1；是否使用的选择至少 1。
- 都市小队分工：职责分工至少 2；状态变化至少 1。
- 异常回收与新责任：阶段性解释至少 1；更高层责任至少 1。
