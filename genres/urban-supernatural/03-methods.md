# 都市超凡 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖破冰、机构、校园、战斗、小队、收尾，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、如何检查、失败了怎么改。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 日常到异常切换

适用：开篇破冰、平静生活被突发打破、异化事件降临、读者需要感受强烈的现实与超常反差。

上场先定：主角正在专注处理的熟悉都市日常任务；打破常识的异常现象物理表现；主角被迫做出的第一次脱险尝试。

步骤：

1. 先建立具有极强代入感的都市日常画面：挤早高峰地铁刷短视频、在便利店加热便当、在自习室刷历年真题。
2. 用一处绝对无法用科学常理解释的物理异常撕碎日常：路人的影子突然反向站立并掐住路人脖子、红绿灯在跳到零秒后变成诡异的猩红符文。
3. 异常迅速演化为致命危机，周围普通人陷入恐慌或失去意识。
4. 主角动用刚觉醒的微弱异能或随身工具进行极限反抗，并在危急关头逃出升天或引来特工介入。

纸上必须看见：一个生活气息浓厚的场景、一次冷酷可怖的常识崩塌、一次带有生理痛感的自救动作。

检查：异常是否切实打破了主角原有的生活节奏；是否避免了一上来就进入架空异界的抽离感。

失败：开篇只有玄幻式的打斗，主角和怪物在一片虚无的荒野上火拼，没有任何现代都市背景元素。改法：把战场直接移到晚高峰的跨江大桥上，让怪物直接撕碎一辆正在鸣笛的网约车。

教学：青年正骑着电动车在暴雨中赶送一份即将超时的麻辣烫外卖。导航语音突然变成滋滋的电流盲音，前方的十字路口路灯同时爆裂。斑马线上，一名打着黑伞的西装男子突然双膝反折跪地，后背的西装被两条覆盖着黑色鳞片的巨型蛛腿硬生生撑破，沥青路面被腐蚀出滚烫白烟。青年猛捏刹车摔在积水中，麻辣烫洒了一地，眼看蛛腿横扫而来，他掌心突然爆发出刺目的白炽电弧，一掌轰断了路旁的水泥电线杆砸向蛛怪。

## 制度化超凡

适用：特特局审讯、资质评定、签署保密条例、超凡执照考核、进入官方管理体系。

上场先定：负责执法的官方机构与标准化测试流程；测试暴露出的主角特质与硬性限制；测试结果如何转化为下一阶段的官方任务。

步骤：

1. 用具有高度现代程序感的设备与话术压向主角：灵能测谎仪、防爆隔离玻璃、全套带编号的保密协议。
2. 让主角在仪器监测下完成标准化异能测试（如力量拳靶、精神力脑电波读数、元素释放阈值）。
3. 明确记录主角获得的官方评级（如「D级特勤调查员」），以及随之而来的严格管理条例（如「闹市区严禁释放三级以上能量，违者移送军事法庭」）。
4. 机构负责人出示第一份正式委派任务书，将主角正式纳入体制运作中。

纸上必须看见：冰冷的测试仪器、确凿的评级数据、签字画押的保密合同、一份带公章的任务档案。

检查：制度流程是否具有严肃的现代组织质感；测试结果是否切实改变了主角的法律权限与社会地位。

失败：官方组织像个草台班子，几个黑衣人把主角带到小黑屋，三言两语就认他当大哥。改法：增加严谨的指纹采集、视网膜扫描、防反噬拘束带以及冷冰冰的法条宣读。

教学：地下三层的特异局综合评定室，四名持枪特警分立四周。主角被固定在钛合金测试椅上，头戴密密麻麻的脑电波电极。主考官按下红色按钮，中央强化玻璃房内升起一座特种合金测力靶。主角深吸一口气，眼眸泛起暗金光芒，隔空一拳轰出，三吨重的合金靶瞬间凹陷出十公分深的拳印，仪器警报狂响，屏幕跳出猩红数据：「精神穿透力：七百二十帕，评定等级：B级危险源」。考官推过一份带有绝密水印的劳动合同：「林澈同学，签字吧。从今天起，你挂靠特异局第七行动组，月薪两万五，五险一金，今晚十二点前去向阳路三号防空洞报到。」

## 校园/机构开篇

适用：高武校园、异能特训营、科研所实习、以学业或组织晋升为主线的开篇章节。

上场先定：主角面临的切身学业或考评压力；三章内交付的超凡测试事实；测试结果带来的身份跃迁与隐藏危机。

步骤：

1. 从具体的校园考评或机构竞争切入：全省高武联考前夕的最后一次模拟摸底、争夺唯一的特种研究所实习名额。
2. 在公开考评或擂台比试中，主角面对冷眼与嘲讽，拿出压箱底的真实本事。
3. 超凡事实在众目睽睽下被仪器或考官权威确认，瞬间打破原有的鄙视链。
4. 获得顶级名校保送或重点培养资格的同时，立刻引来竞争对手背后的财阀黑手或暗杀势力。

纸上必须看见：一张真实的成绩单/考评表、一次全场寂静的打脸实测、一份沉甸甸的录取通知、一道投来的暗杀视线。

检查：校园竞争是否与超凡晋升体系严密结合；是否避免了无脑打脸的幼稚化描写。

失败：主角全校倒数第一，突然当众大展神威把全校师生暴打一顿，老师不仅不报警还当场下跪。改法：让主角用严谨的武道理论和标准发力技巧，在全息监测靶上打出超乎常理的极限数据，引得巡考组军方大校当场起立抢人。

教学：江城一中的高武体测室内，拳力测试机前排着长队。主角作为气血值常年垫底的贫困生，被排在最后一个。当他站上测力台，深吸一口气，体内悄然运转融合了雷电属性的引气诀，右拳如炸雷般轰在受力皮垫上！轰然巨响中，测试机背后的散热风扇冒出黑烟，电子液晶屏疯狂闪烁后定格在刺目的「1280KG（远超重点线）」！整个室内瞬间死寂。坐在主考席上的省城特招教官猛地站起身，直接撕碎了原本写好保送名字的推荐表：「这个学生，军方要了！」

## 能力—代价—选择

适用：街头遭遇战、高危收容、生死解救、在绝境中必须动用禁忌力量的章节。

上场先定：主角动用异能能达到的即时战果；施展该能力对肉体、精神或隐秘值造成的残酷反噬；被迫在两个带代价的方案中做出选择。

步骤：

1. 写清当前战局的绝境与目标：异化怪物即将突破防暴盾牌、同伴被困在着火的写字楼顶层。
2. 列出主角动用底牌必须支付的沉重代价：开启二阶段狂暴会抽干三天寿命、释放极寒领域会导致右手永久冻伤坏死。
3. 主角经过权衡，毅然做出选择，以自身残损为代价完成致命一击。
4. 战后展示清晰的生理账本与后续生活不便，绝不立即恢复如初。

纸上必须看见：致命的战局压迫、一次带血的能力爆发、战后惨烈的身体反噬、散场后确凿减少的自保资本。

检查：代价是否真实阻碍了主角接下来的行动；选择是否展现了主角坚守的底线与人性。

失败：主角动用了号称「使用即死」的终极禁咒，打完怪之后只是擦了擦鼻血，第二天继续活蹦乱跳。改法：让主角在战后直接昏迷送进ICU，右臂缠满石膏绷带，且整整三个章节内无法使用右手。

教学：商业中心地下车库，狂暴化的三阶铁甲巨蜥正用尾巴疯狂抽打承重柱，整栋大楼摇摇欲坠，身后是躲在防弹车里吓哭的普通母女。主角手中的配枪子弹全部打光，他咬碎嘴里的高浓度镇静剂胶囊，强行解开被封印的「熔岩过载」天赋。刹那间，他整条右臂的皮肤如干裂的焦炭般寸寸崩裂，滚烫的赤红岩浆从血管中喷涌而出，一记贯穿重拳将巨蜥的头颅硬生生轰入水泥地面！巨蜥毙命，大楼保住了。主角右臂焦黑碳化垂在身侧，剧烈的神经痛让他单膝跪地大口呕血——他赢了，但这条右手在找到稀有治愈系异能者之前，彻底沦为废肢。

## 都市小队分工

适用：小队夜巡、现场勘查、围剿异端组织、团队配合破局。

上场先定：小队成员各自分立的异能属性与战术职责（前排抗伤、远程狙杀、结界封锁、后勤信息支援）；信息差引发的战术分歧；结果如何重排团队信任。

步骤：

1. 标明小队各成员的代号、异能类型与战术站位：队长负责正面吸引火力、结界师负责拉起两百米禁行结界防平民误入、主角负责暗影潜行突刺。
2. 在执行清剿过程中，因情报不准或突发意外产生严重分歧（是冒着结界破碎的风险强杀目标，还是立刻撤退呼叫空中打击）。
3. 主角与队友依靠各自的能力互补与极限默契，在电光火石间化解分歧，完成战术配合。
4. 任务结束后，根据实战表现重新划分战利品分配与小队核心话语权。

纸上必须看见：清晰的战术分工配合、一次因为信息差导致的临场决断、散场后确凿加深的团队羁绊。

检查：每个队员的能力是否都在破局中发挥了不可替代的作用；是否避免了主角一个人单刷全场把队友写成废物的毒点。

失败：全队除了主角全员划水，遇到危险只会抱头痛哭喊救命。改法：给队友设计硬核的高光动作——狙击手在千米外顶着狂风盲射打爆怪物眼球，给主角创造绝杀机会。

教学：雨夜废弃港口，第七行动组正在伏击异教执事。队长暴喝一声化身三米高的合金巨人，硬顶着密集的腐蚀骨刺撞碎集装箱；结界师少女双膝跪地双手按住地面，精神力化作湛蓝光罩死死锁住港口，防止毒气扩散至相邻居民区。潜伏在阴影中的主角接到狙击手的热感坐标指示：「风速三级，目标咽喉下方三寸核心暴露，时效一秒！」主角自阴影中暴起，手中高频振动短刃如黑夜闪电般抹过执事的喉管！骨刺停歇，结界解除。队长拍了拍主角的肩膀，从怀里掏出一根香烟递过去：「小子，干得漂亮，下个月的副队长津贴，归你了。」

## 异常回收与新责任

适用：事件收尾、封印禁忌物、向高层交差、兑现阶段性奖励、引出更深层城市危机。

上场先定：本场彻底解决并收容的异常标的；高层给予的实质性嘉奖与权限提升；因本次事件意外牵扯出的更高层级威胁。

步骤：

1. 用严密的专业收容流程将击败的异常目标或禁忌物封装入库（如装入铅封密码箱、贴上特异局封印符纸）。
2. 主角向特管局高层提交战后报告，兑现功勋点、现金奖励或特殊修炼资源。
3. 庆功宴未尽之时，高层告知一个残酷的后续调查事实：被击败的异化体只是某个庞大跨国集团人体实验的失败残次品。
4. 章末把新威胁转化为下一阶段必须追踪的长期潜伏任务。

纸上必须看见：一个严密的收容封装动作、一笔到账的实质奖金或资源、一份揭开冰山一角的高级机密档案。

检查：局部危机是否彻底解决；新任务是否由本次收容结果自然引出而非凭空砸来。

失败：打完怪就原地散会，没有任何后续收容和组织反馈，故事断崖式停滞。改法：主角拿着收容盒回到局里，局长亲自从保险柜里取出能够修复他受损经脉的特等灵液作为赏赐。

教学：特制铅封箱合拢上锁，特勤人员用喷火枪将现场所有残留的异化组织彻底焚化成灰。回到特异局总部，电子账户提示音响起：「您的功勋账户已到账三千积分，现金补贴十万元已发放」。然而当局长将战利品报告推到主角面前时，神色却无比凝重：「我们从这具异化体的大脑里提取出了一块微型芯片，编码属于本市最大的跨国药企——天穹生物。下周天穹生物将在国宾酒店举行慈善晚宴，你的新任务是以安保顾问身份潜入晚宴，找到他们的地下实验室。」
