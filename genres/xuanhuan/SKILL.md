# 玄幻写作

## 触发条件

项目或用户任务是玄幻、东方玄幻、异界、高武，或明确要求按玄幻方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要编完整等级表。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认卖点、初始压力、力量触发与边界、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章可执行压力，第2章可验证超常事实，第3章一次反馈加可行动问题。顺序可按卖点调整。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「三章超常承诺 / 力量体系边界设计 / 获得—代价—下一阈值 / 后果先行的世界展示 / 因果选择场景 / 回报伴随新压力」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见 → 本场计数」执行。
6. 成文：句长约 20–30 字，段长约 30–35 字，对白大约两成上下。先写后果再补规则。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 力量能被行动看见
- 获得留下代价或下一阈值
- 规则改变选择
- 章末有下一步能做的事

## 硬约束

- 读者承诺：在可观察的超常规则里争夺力量和位置
- 不要开篇先列完整等级表
- 不要把第一章异变当成所有玄幻的开场模板
- 区间不是合格线；解释打断动作比数字偏离更严重

本场计数按所选写法执行，数字只来自该写法的量化控制：

- 三章超常承诺：可执行压力至少 1；可验证超常事实最晚第 3 章交付；可行动问题为 1 到 3。
- 力量体系边界设计：可观察反馈至少 1；边界、代价或失败条件至少 1；不要完整等级表。
- 获得—代价—下一阈值：获得至少 1；代价或限制至少 1；下一阈值至少 1。
- 后果先行的世界展示：必须先写可观察后果，再补解释；因新信息改变的下一步至少 1；独立设定段最多 1。
- 因果选择场景：当前目标至少 1；局面升级至少 1；可观察选择至少 1；状态变化至少 1。
- 回报伴随新压力：兑现的回报至少 1；回报带来的新压力至少 1；可执行的下一步至少 1。
