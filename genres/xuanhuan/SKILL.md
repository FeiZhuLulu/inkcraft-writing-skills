# 玄幻写作

## 触发条件

项目或用户任务是玄幻、东方玄幻、异界、高武，或明确要求按玄幻方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认卖点、初始压力、力量触发与边界、前三章承诺。缺一项就先问作者，不要编完整等级表。
4. 开篇：第1章现实压力，第2章可验证超常事实，第3章一次反馈加可行动问题。
5. 章内：按本章功能选用「力量边界 / 获得—代价—下一阈值 / 后果先行 / 因果选择 / 回报伴随新压力」。
6. 成文：句长约 20–30 字，段长约 30–35 字，对白大约两成上下。先写后果再补规则。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 力量能被行动看见
- 获得留下代价或下一阈值
- 规则改变选择
- 章末有下一步能做的事

## 硬约束

- 读者承诺：在可观察的超常规则里争夺力量和位置
- 不要开篇先列完整等级表
- 不要把第一章异变当成所有玄幻的开场模板
- 区间不是合格线；解释打断动作比数字偏离更严重
