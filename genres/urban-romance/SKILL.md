# 都市言情写作

## 触发条件

项目或用户任务是都市言情、言情、都市爱情，或明确要求按都市言情方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物小传、情感大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要凭空脑补对方心声。
2. 判断当前任务：开书设计、前三章、互动推进、关系破防，还是审阅。
3. 开书：确认关系核心张力、双方底线与旧伤、现实接触通道、阻力、前三章承诺、本卷两道边界门槛。展开读 `01-structure.md`。
4. 开篇：第1章关系重逢或现实任务触发，第2章用误读或身份差施压，第3章锁死持续接触通道并形成下一步关系选择。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「首次化学反应 / 潜台词对话 / 关系边界位移 / 冲突与退缩 / 日常互动升级 / 修复与确认」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见」执行。
6. 成文：句长约 15–25 字，段长约 20–35 字，对白大约两成到三成。先写行为与潜台词再推情绪。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 关系变化由可观察的行为信号与空间边界证明
- 对白具备清晰的表层目标与深层潜台词差异
- 冲突与互动改变下一次接近的权限与成本
- 章末留下下次见面的具体借口或未决选择

## 硬约束

- 读者承诺：用可观察的互动、边界和选择推进关系，让情感变化落到共同生活的现实成本中
- 不要靠旁白直接宣布心动或深情
- 不要写悬浮于现实生活之外的工业糖精
- 区间不是合格线；心理直白解说打断暧昧张力比数字偏离更严重
