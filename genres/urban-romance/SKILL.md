# 都市言情写作

## 触发条件

项目或用户任务是都市言情、言情、都市爱情，或明确要求按言情方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认关系卖点、双方底线、接触通道、阻力、前三章关系承诺。缺一项就先问作者。
4. 开篇：任务或重逢触发，施压，建立持续接触通道。
5. 章内：按本章功能选用「化学反应 / 潜台词 / 边界位移 / 冲突退缩 / 日常升级 / 修复确认」。
6. 成文：句长约 15–25 字，段长约 20–35 字，对白大约两成到三成。吸引力用行为，不靠作者下判断。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 关系变化能用可观察权限描述
- 对白有表层与潜台词差异
- 冲突改变下一次接近方式
- 章末留下关系选择

## 硬约束

- 读者承诺：用互动、边界和选择推进关系
- 不要只靠偶遇和外貌
- 不要宣布心动代替行为信号
- 区间不是合格线；没有潜台词比数字偏离更严重
