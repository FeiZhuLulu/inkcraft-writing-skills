# 无限流 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖规则、分工、倒计时、开篇、结算、高潮，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、如何检查、失败了怎么改。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 副本规则落地

适用：进入新区域、遭遇新型诡异机制、摸索杀人规律、破除假生路陷阱。

上场先定：副本在此处生效的客观限制与即死条件；本次行动只验证的唯一关键变量；规则摸清后带来的通关路径改变。

步骤：

1. 让副本规则通过可执行的物理限制或惨烈示范呈现出来（如踏上红地毯的人当场自燃、发出超过四十分贝声音的房间被铁水灌注）。
2. 主角保持绝对冷静，观察现场环境，提出可证伪的规则猜想。
3. 利用现场道具或环境碎片，严格控制变量进行一次低风险试错。
4. 将试错结果结算为明确的通行法则，彻底改写下一步的行动方案。

纸上必须看见：一个不可违背的硬性禁忌、一次带代价的变量测试、一条被验证的通关新规则。

检查：规则是否符合严密的逻辑；读者能否跟随主角的推导过程看懂为什么这么做。

失败：主角闭着眼睛瞎蒙，或者靠旁白直接念出答案，读者完全不知道规则是怎么总结出来的。改法：让主角先扔出一块手表测试重力场，再扔出一瓶水测试腐蚀性，分步推导出正确路径。

教学：走廊尽头的红木大门每隔六十秒就会喷出一次致命毒雾。主角手头只有一块秒表和三枚铜币。他观察到前两名死者都是在迈出第七步时被毒雾喷中。他按下秒表，将第一枚铜币在第十秒抛入走廊，铜币落地无声；第二十秒抛出第二枚，地砖突然亮起红光并提前喷出毒雾！主角瞬间明白：「毒雾不是定时的，而是根据脚步踩踏地砖的累计压力蓄力触发！」他立刻吩咐全队脱掉沉重的皮靴，换上防滑棉袜，贴着受力最小的墙角木梁以三点受力无声爬过。

## 副本队伍分工

适用：团队攻坚、生死防守、多线解谜、新人与资深者博弈、信任重组。

上场先定：团队成员各自分立的特长与自私生存动机；信息差引发的战术分歧；分工协作带来的不可逆状态改变。

步骤：

1. 明确划分探索者、推理者、主攻手与后勤诱饵的职责边界与行动点位。
2. 利用各自隐瞒的情报或阵营任务，制造出即时性的战术冲突与利益博弈。
3. 主角凭借绝对的专业判断或利益制衡，在危机降临瞬间强行压制分歧，完成战术咬合。
4. 任务阶段性达成，但有人因此受伤、有人消耗了底牌，小队内部的权力与信任格局彻底重排。

纸上必须看见：清晰的点位分工、一次因为私心引发的危险摩擦、散场后确凿改变的队伍阵营关系。

检查：分工是否真正影响了任务结果；是否每个队员都展现了符合人性的求生逻辑。

失败：全队所有人都是主角的跟班，毫无个人主见，让去送死就排队去送死。改法：给资深者加上暗中扣留解药以要挟新人的自私算计，逼主角在关键时刻用规则反杀夺权。

教学：古堡四楼的密室需要三把钥匙同时插入三个不同方位的锁孔。资深者持枪命令主角去最危险的血池取第一把钥匙，自己则守在安全的中央大厅；主角冷笑一声，指出中央大厅的石像鬼其实才是真正的处决者。他提出交易：敏捷最高的新人去血池，资深者去偏厅拉下电闸吸引石像鬼，自己负责在中央大厅开锁。三方相互制衡，不得不各就各位。当机关转动、大门轰然开启的刹那，资深者被石像鬼抓伤了一条手臂，而主角不仅拿到了钥匙，还顺势夺过了小队的绝对指挥权。

## 倒计时资源选择

适用：极限逃生、防线崩溃、撤离点倒计时、背包物资耗尽、必须舍弃一人或一件道具。

上场先定：跳动在眼前的精确倒计时秒数；所剩无几的消耗品清单；两个代价不同但都成立的逃生方案；最终舍弃的具体标的。

步骤：

1. 亮出具体到个位数的倒计时与生存资源账本（逃生舱发射倒计时还剩四十五秒、氧气瓶剩余最后两分钟、唯一的传送符只够传送一人）。
2. 摆出两个互斥且充满道德与生存痛苦的方案：启动自毁程序炸开生路但会毁掉所有积分战利品；强行硬抗BOSS一击带走重伤队友但可能全灭。
3. 人物在极度紧迫的时间压迫下，凭借自身冷酷或底线做出决断并迅速执行。
4. 结算选择后果，明确记录少掉的装备或死去的队友。

纸上必须看见：跳动的倒计时数字、一份清清楚楚的物资缺口账单、一次带血的决绝放弃。

检查：时间与资源是否具有真实的物理紧迫感；决断是否切实排除了另一个选项。

失败：倒计时数到了零秒，主角还在慢悠悠讲大道理，讲完之后还能轻松把两边的利益全占光。改法：严格卡准十秒生死线，主角在最后一秒毫不犹豫斩断被怪物咬住的防化服下摆，舍弃了整整半包珍贵道具才跃入逃生舱。

教学：防空洞大门还有三十秒彻底锁死。门外是狂暴的丧尸潮，门内是通往通关传送阵的安全通道。主角手中只有最后一颗温压手雷，身旁是断了一条腿无法行走的资深者。资深者哀求主角背他，但背上他两人都会被关在门外。倒计时跳到「00:00:12」，主角拉开手雷保险环，将手雷塞进资深者怀里：「按住引信，给全队争取十秒，你的抚恤金积分我回空间全打给你妹妹。」主角转身飞扑滚入大门，大门合拢的刹那，门外传来了震耳欲聋的爆炸与惨叫——全队通关了，但主角背包里多了一张染血的欠条。

## 规则未全知的开篇

适用：开书第一章、初入死亡副本、信息严重缺失、需要在未知中建立悬念与破局点。

上场先定：主角苏醒时的封闭危险环境；第一条通过死亡示范呈现的即死规则；主角拿到的残缺线索与首个必须完成的自救动作。

步骤：

1. 主角在毫无准备的情况下置身于充满恶意的封闭死亡场景中（解剖台、绞刑架、深海潜水舱）。
2. 在规则完全未明的情况下，其他受害者盲目行动，当场触发即死陷阱暴毙，为主角提供第一手血腥情报。
3. 主角凭借超强的心智抗压能力，在残缺的告示牌、地上的血字或随身物品中拼凑出生路线索。
4. 在三章内完成一次具有决定性意义的规则反转或首杀，交付第一笔生存回报。

纸上必须看见：一个令人窒息的开局环境、一次惨烈的死亡示范、一张残缺但真实的线索卡、一次绝境自救。

检查：未知的恐惧是否公平可解；主角的破局是否完全建立在已知线索的合理推导上。

失败：开篇没有任何线索，全靠主角身上突然觉醒的无敌外挂直接把副本炸碎。改法：把外挂改成主角敏锐的视力，让他从死者鞋底的泥土颜色推断出真正的安全区在三号仓库。

教学：主角在冰冷的停尸房冰柜中醒来，胸口贴着一张写着自己名字的死亡标签。冰柜外传来粗重的咀嚼声，旁边几口冰柜的受害者惊慌踹门跳出，刚落地便被无形的阴影撕成碎片。主角死死按住冰柜门，在黑暗中摸索到冰柜内侧刻着的一行歪扭血字：「尸体绝不能离开带有冷气的抽屉」。当外面的阴影拉开他的抽屉时，主角屏住呼吸，抓起冰柜里的冰块塞进嘴里强行降低体温，阴影在他冰冷的面孔上嗅了三秒，缓缓推上了抽屉——第一重即死规则被成功破解。

## 副本结算回写主线

适用：通关结算、重返空间、分配奖励、修复创伤、强化属性、主线状态更新。

上场先定：本局通关获得的全部积分、评级与专属道具清单；副本中承受的不可逆身体或精神创伤；结算结果如何彻底改变主角在轮回空间中的地位。

步骤：

1. 冰冷的系统机械音播报通关评价（S级、超额完成隐藏支线），清点获得的积分与特殊技能卡。
2. 传送回调度大厅或个人专属安全屋，立刻进行肉体修复并扣除相应积分，记录未能完全修复的心智或属性暗伤。
3. 主角利用奖励进行精准的属性强化或装备锻造，形成全新的战斗体系。
4. 结算结果引起空间各大公会或高阶资深者的注意，主线人际与阵营地位发生实质跃迁。

纸上必须看见：一份严密的数字与道具清单、一次真实的疗伤与属性强化、一个在空间中彻底改变的新身份。

检查：奖励是否切实提升了主角的实力；是否避免了数字通胀导致的战斗力崩坏。

失败：通关后发了几千万积分，主角买了一堆神级装备，下一局副本却依然打得和普通人一样吃力。改法：严格控制积分购买力，两千积分只能兑换一把附带破甲属性的左轮手枪与三支强效解毒剂，每一分钱都花在刀刃上。

教学：【副本结算完成，通关评价：S+，获得轮回积分：5000点，获得专属道具：深渊凝视者之眼（传说级）】。光芒闪过，主角回到私人空间，花费八百积分修复了左臂粉碎性骨折。他坐在工作台前，将深渊之眼镶嵌进自己的战术手套，手套立刻解锁了「可勘破三阶以下幻术」的词条。推开安全屋大门，调度大厅的排行榜大屏幕上，他的代号「夜枭」已赫然升至新人榜榜首，两名来自顶尖公会「裁决所」的黑袍使者正站在门外等候接见。

## 通关后的更高风险

适用：大副本收束、高潮揭示、更高阶副本征召、调度空间的深层黑幕暴露、章末钩子。

上场先定：本场彻底兑现的通关成就与旧谜底；伴随高额评价而来的更高阶死亡惩罚或对抗机制；新危机如何写成下一局的必做任务。

步骤：

1. 彻底解决眼前的副本主线，让主角享受到智斗胜利的巅峰快感。
2. 在享受回报的瞬间，调度系统或空间机制立刻降下冷酷的惩戒性规则或大逃杀征召。
3. 揭示出主角因表现过于优异，已被列入更高层级、全员皆是怪物的死亡猎杀名单。
4. 章末把生存压力转化为下一局必须提前准备的特殊克制道具。

纸上必须看见：一个完满的胜利终点、一份冰冷的新战书、一个迫在眉睫的下一局生死考验。

检查：新风险是否源于主角此前的出色表现而非作者无理刁难；下一局任务是否具有清晰的应对方向。

失败：通关后全篇陷入无事可做的休假模式，连水三章逛街买衣服。改法：在主角刚踏出副本的瞬间，调度核冰冷播报：由于触发隐藏成就，三天后将强制进入「无光猎场」百人淘汰副本。

教学：当最后一头古神眷属在火海中哀嚎倒下，通关光柱将全队笼罩，主角长舒一口气瘫坐在地。然而还没等笑容完全绽开，调度核冰冷刺耳的红色警报声响彻整个空间：【警告！编号9527玩家以单人斩杀形式通关S级副本，触发空间平衡制约机制！下一局副本已被锁定为跨阵营生存战——‘无光之海’，你将作为全场唯一的‘狩猎目标’，面对三支资深猎杀者小队的联手追杀！】倒计时：72小时。主角握紧了手中的战术短刃，眼神瞬间变得比冰雪更冷。
