# 无限流写作

## 触发条件

项目或用户任务是无限流、诸天流、副本、轮回，或明确要求按无限流方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认副本规则、队伍、倒计时或资源、结算如何回写。缺一项就先问作者。
4. 开篇：规则不全时行动，出现分工或倒计时，兑现反转或收益。
5. 章内：按本章功能选用「规则落地 / 队伍分工 / 倒计时选择 / 结算回写 / 更高风险」。
6. 成文：句长约 20–35 字，段长约 25–35 字，对白大约一成到两成。一次只测一个变量。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 规则可复盘
- 结算改变下一局
- 未知对读者公平
- 章末有新任务或新风险

## 硬约束

- 读者承诺：局部闭环，收益改变下一局风险
- 不要写成说明书
- 不要让损失清零
- 区间不是合格线
