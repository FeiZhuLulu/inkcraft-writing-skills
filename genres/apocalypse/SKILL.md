# 末世写作

## 触发条件

项目或用户任务是末世、灾变、废土、生存，或明确要求按末世方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要编宏大世界史。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认生存卖点、初始资源短缺、威胁规则与边界、秩序状态、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章生存日常与异常侵入，第2章扩大风险与秩序尺度，第3章交付能力或生存契机并形成下一步行动问题。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「灾变压力开篇 / 威胁规则展示 / 秩序位置变化 / 危险区搜索 / 资源短缺选择 / 团队生存决策」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见 → 本场计数」执行。
6. 成文：句长约 20–35 字，段长约 25–40 字，对白大约两成上下。先写后果再补规则。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 威胁通过具体物理与生理后果被看见
- 资源消耗可追踪且影响行动选择
- 秩序规则改变人物生存权限
- 章末有下一步必须执行的求生动作

## 硬约束

- 读者承诺：在持续恶化的环境与秩序中，用具体选择换取生存、资源与位置变化
- 不要开篇只有全景灾难景观而无主角个人求生目标
- 不要让物资无限充沛或无代价刷新
- 区间不是合格线；解释打断求生动作比数字偏离更严重

本场计数按所选写法执行，数字只来自该写法的量化控制：

- 灾变压力开篇：可执行生存目标至少 1；威胁尺度升级至少 1；必须留下可行动钩子。
- 威胁规则展示：按旧规则行动的尝试至少 1；可供下次决策使用的信息至少 1。
- 秩序位置变化：权限变化至少 1；变化后的行动约束至少 1。
- 危险区搜索：信息增量为 2 到 4；搜索方法调整至少 1；没有信息增益的搜索节拍最多 1。
- 资源短缺选择：互斥方案至少 2；写明的代价至少 1；必须写出选择后的库存或关系后果。
- 团队生存决策：互斥方案至少 2；必须写明决策者；必须写明代价承担者。
