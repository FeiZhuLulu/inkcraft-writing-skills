# 末世写作

## 触发条件

项目或用户任务是末世、灾变、废土、生存，或明确要求按末世方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认生存卖点、初始资源与底线、威胁规则、秩序状态、前三章行动承诺。缺一项就先问作者。
4. 开篇：第1章生存压力，第2章扩大尺度，第3章交付能力、遗迹或行动承诺。
5. 章内：按本章功能选用「威胁规则 / 秩序位置 / 危险区搜索 / 资源短缺 / 团队决策」。
6. 成文：句长约 20–35 字，段长约 25–40 字，对白大约两成上下。先写生存后果，再补灾变解释。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 选择改变了资源、秩序或位置
- 威胁通过事件被证明
- 章末有可行动的风险或选择

## 硬约束

- 读者承诺：用具体选择换生存、资源与位置
- 不要三章只展示灾变设定
- 不要让选择不消耗库存、时间或关系
- 区间不是合格线；解释打断求生动作比数字偏离更严重
