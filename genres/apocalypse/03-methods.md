# 末世 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖开书、规则、秩序、搜索、短缺、带队，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、如何检查、失败了怎么改。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 灾变压力开篇

适用：开书、黄金三章、灾变刚侵入、读者可能以为这只是普通灾难新闻或社会混乱。

上场先定：主角今晚必须处理的一件具体求生任务；那处让旧常识彻底失效的致命异常；前三章要把威胁扩大到哪一层公共空间或人类秩序。

步骤：

1. 先给主角一个具体可执行的生存目标。接水、换药、救助亲属、赶在宵禁与毒雾合拢前返回掩体，选一个能动手的。
2. 用一处异常让旧常识硬生生碰壁失效。水龙头喷出带毒铁锈灰、手机信号全部乱码、平日坚固的防盗门被利爪撕开薄纸般的口子。
3. 将危机从个人房间迅速推向公共空间与秩序层面：整栋楼的供水断绝、邻居为争夺口粮火拼、守卫封锁街道无差别扫射。
4. 交付一次超常自救或底牌觉醒，并在章末留下明确的下一次突围任务。

纸上必须看见：一件当夜必须完成的目标、一次旧常识碰壁、一个更大尺度的危机扩散、一个下一步动作。四样缺一，开篇不成立。

检查：异常是否迫使主角采取实质行动而非仅仅制造惊悚氛围；读者应能明确说出他今晚必须保住什么。

失败：只有全景灾难景观。浓烟、警报、血迹与废墟充斥全篇，主角却坐在窗前发呆感叹，没有任何个人紧迫求生目标。改法：异变中必须加一件他今晚必须保住的口粮或药品，把全城沦陷放到背景中，第一章把个人生存缺口写死写硬。

教学：储水罐只剩最后一升。青年摸黑爬上顶楼水箱，阀门滚烫，拧开却喷出刺鼻的白磷蒸汽与空响。他退回五楼时，单元门已被人从外面焊上角铁封死，走廊里传来撕咬声。他必须在天亮前破开通风管跳往隔壁天台——个人缺水在半小时内升级为整栋楼的封死与突围绝境。

## 威胁规则展示

适用：新型威胁或变异生物第一次上场、旧战斗手段被证伪、人物准备按灾变前的经验硬拼。

上场先定：人物依据的旧规则是什么；准备用哪一次行动去正面撞墙；失败后留下哪条可供下次决策使用的硬核信息。

步骤：

1. 让人物先按旧世界的常识或常规战术行动。关紧铁门就安全、开枪能吓退野兽、煮沸就能净化水源，先让他当真去执行。
2. 用惨烈失败或异常反馈证明旧规则彻底作废。关门反而被气味追踪、枪声引来更大围攻、水烧开反而析出浓缩毒素。
3. 人物付出真实代价（损耗弹药、负伤、丢弃背包）后脱身，并提炼出至少一条可复用的新规则。
4. 将新规则立刻应用到接下来的行动中，改变下一步行进路线或防守策略。

纸上必须看见：一次按旧法出手、一次当场被打脸、一条能带进下一场决策的新威胁认知。

检查：规则变化是否由具体的物理/生理事件证明，而不是旁白直接宣布「从今天起夜晚的怪物不怕火」。

失败：旁白宣布新世界法则。人物还没试错过，读者已经听完作者洋洋洒洒的怪物生态学讲座。改法：删掉讲座，留一次主角开枪不退反被扑倒的生死瞬间，把新规则写成他在血泊中领悟出来的半句话。

教学：他照旧把防盗铁门反锁，以为在屋里便能安睡。门缝突然渗进带酸味的黑水，合金门锁在数秒内被腐蚀成铁水，门外阴影根据他急促的呼吸声精准撞击门板。他不得不扔下电筒改用湿布死死捂住口鼻贴地爬行，撞击声果然顿止——怪物没有视力，只靠嗅觉酸反应与呼吸声猎杀。这条规则立刻成为后续潜行穿过走廊的关键依仗。

## 秩序位置变化

适用：组织、军阀、壁垒、拾荒队、据点第一次改变主角的社会身份与生存权限。

上场先定：用什么具体物件或程序落实秩序（臂章、铁牌、流民登记表、抓捕名单）；变化后能做与不能做的各一条；新位置把下一步行动引向哪里。

步骤：

1. 用具体身份凭证、检查岗哨或暴力抓捕将秩序压到现场。不要写抽象的「这座据点实行军管」，要写卫兵端枪索要什么、查验什么。
2. 明确身份转变后人物获得的特权与面临的苛刻禁令。持有外围铁牌可以进集市买水，但严禁踏入内城，违者当场击毙；登记为劳工能领半碗糙米，但必须服夜间清污劳役。
3. 让新的秩序位置直接改写主角的下一步路线与目标。
4. 留下秩序内部的潜在冲突或漏洞，为后续撕破该阶层埋下伏笔。

纸上必须看见：一次具体的被查验或被收编、一条不可逾越的行动红线、一个因此被彻底改道的下一步目标。

检查：秩序变化是否切实改变了角色的物理行动权限。换了个新称号但能走的路和能领的饭与之前毫无区别，这场戏作废。

失败：只换虚名而边界未变。主角被封为「先锋队长」，但进出关卡依然随意，没有配给限制也没有上级监管。改法：给新身份套上一道沉重的紧箍咒——虽然获得队长配枪，但每周必须上缴三十公斤纯净水，否则全队取消配给。

教学：流民关卡前，铁丝网拉起三道防线。主角交出仅有的两盒消炎药，换来一块带有编号的青铜工牌，被登记为「丙级拾荒者」。持此牌他能合法在集镇外围搭棚过夜、购买低纯度饮用水，但卫兵冷冷告诫：夜间八点后若在乙区街道出现，无需警告直接射杀。他暂时保住了命，但想要救治发烧的同伴，必须在三天内攒够功勋换取能进甲区药房的银牌。

## 危险区搜索

适用：搜寻关键物资、探索废弃遗迹、进入重污染区、复查疑似藏有幸存者的空楼。

上场先定：可验证的搜索目标与明确空间范围；准备按什么顺序推进并排除假目标；撤出场景时必须带走的资源、敌情或新问题。

步骤：

1. 给出明确可衡量的搜索目标与空间范围。「三楼西侧药房的冷藏胰岛素」「地下机房的发电机还能否点火」，不要模糊的「进城碰碰运气」。
2. 连续设置至少两次信息增量与排除点。脚印是新鲜的说明刚有人来过、冷柜断电化水说明药品已变质、仪器发热证明怪物还在附近筑巢。
3. 用突发险情、地形塌陷或装备故障迫使搜索方法发生一次紧急调整。
4. 退出场景时完成结算：带走目标物资，或者带回致命敌情与未解新谜团。

纸上必须看见：具体目标、清晰的排查推进过程、一次战术被迫调整、退出时的实质性战果或新危机。

检查：搜索过程是否持续向读者释放有效信息。读者应能清晰复述主角排除了哪几个房间、为什么中途改变路线。

失败：空转一圈。主角在废墟里晃荡了三千字，翻箱倒柜毫无阻碍，既没有危险博弈也没有带回决定性物资或情报。改法：每推开一扇门就必须划掉一种可能，并让手电筒电池耗尽或楼板坍塌逼迫他改变前进方式。

教学：目标是社区卫生站二楼的抗生素。推开一层铁栅栏，地面灰尘上有三道拖拽血痕，药柜全空；他顺着血痕改走外墙排水管翻入二楼处置室。冷藏箱锁着，撬开后发现药剂尚存三支，但箱底贴着一张带血的字条，写着三小时前的日期与另一支搜寻队的求救代号。他拿到了救命药，同时也得知卫生站地下室正困着一群持枪的残兵。

## 资源短缺选择

适用：水、粮、药品、弹药、蓄电池、车位、防毒滤芯不足，必须在两个可行方案中彻底抛弃一个。

上场先定：库存、需求与缺口的精确数字；两个代价不同且都合理的互斥方案；按主角价值底线先保什么、舍弃什么。

步骤：

1. 量化当前的物资库存、消耗速度与缺口数字。只剩两瓶纯净水、三发霰弹枪子弹、蓄电池电量剩余百分之十五，写出确切数字。
2. 摆出至少两个互斥且具有可行性的方案。用最后的电量净化水，就无法启动无线电向救援队发射定位；用防毒面具救重伤的向导，主角自己就必须在毒雾中屏气突击。
3. 人物根据自身底线与生存逻辑做出取舍，并公开承受损失。
4. 清晰展现选择后的物资账本与人际关系后果。

纸上必须看见：具体的缺口数字、两个不可兼得的方案、一次带血的放弃、散场后确凿少掉的生存依托。

检查：是否真正排除了另一个方案。绝不能口头上表现得很痛苦，实际上一番骚操作把两边的利益都占全了。

失败：两头皆大欢喜。既省下了子弹又救回了所有人，物资还神奇地在废墟角落重新捡到。改法：必须让被放弃方案的损失化为实质性的后续灾难——放弃了给卡车加油，主角团队接下来的三十公里必须在暴风雪中徒步前行。

教学：越野车油箱见底，抽出的最后一桶柴油仅够驱动一次设备。方案A：倒入发电机，维持地下避难所冷气运转，保住里面储存的变异兽肉干；方案B：倒入卡车，立刻载着高烧的弟弟冲往二十公里外的流民集镇求医。他沉默三秒，将柴油全部倒进卡车油箱。卡车启动了，但避难所里的数百斤肉干在高温下彻底腐烂报废——弟弟或许能得救，但全队下个月将面临绝对断粮。

## 团队生存决策

适用：队伍撤退、危险救援、路线分歧、人员分流、据点决定是否接纳危险陌生人。

上场先定：团队共同目标、各成员面临的差异化风险、退出底线；两种互斥路线；谁拍板定案、谁承担额外风险、谁被牺牲或边缘化。

步骤：

1. 写清团队当前目标与迫在眉睫的灭顶危机。暴风雪还有半小时封山；队伍里有一名断腿队员和一名孕妇；卡车空间只能再载两人。
2. 摆出两种都有充分依据的争执方案。保守派主张就地依托破屋固守，激进派主张抛弃辎重全员轻装强行翻山。
3. 决策者站出来拍板，并明确指定谁来承担最危险的断后任务或放弃谁的利益。反对者必须有坚实的生存依据，不能只负责胡搅蛮缠。
4. 决策落地后，立即改变队伍编制、行军阵型与成员之间的信任关系。

纸上必须看见：互斥的生存主张、一次有明确责任人的独断决定、落到特定成员身上的沉重代价。

检查：反对派的方案是否有立得住的生存逻辑；代价是否切实落到具体角色身上，而不是全员举手和平通过。

失败：全员圣母心泛滥毫无分歧，或者反对者被塑造成纯粹的无脑恶人被主角一枪崩掉。改法：赋予反对者合理的自保依据（如「带上伤员大家在雪地里连三公里都走不完」），并让被抛弃或被命令断后的人留下深远的仇怨或牺牲震撼。

教学：变异狼群循着血迹逼近山洞，洞内弹药告罄，风雪正掩盖下山小径。老枪手主张把受伤昏迷的斥候留在洞里吸引狼群，全队借机从悬崖索道滑降；主角坚持背着斥候突围。队长夺过引爆器拍板：全队带斥候立刻滑降，老枪手负责在洞口开三枪并引爆最后的雷管断后。老枪手惨笑一声接过雷管，骂了一句却拉开保险栓。队伍突围了，但唯一的重火力手永远留在了山洞，主角背包里沉甸甸地多了一块老枪手托付的遗物怀表。
