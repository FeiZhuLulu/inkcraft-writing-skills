# 游戏轻喜剧写作

## 触发条件

项目或用户任务是游戏、轻小说、沙雕、搞笑，或明确要求按游戏轻喜剧方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认可测游戏目标、规则反馈、队伍差异、笑点后如何结算。缺一项就先问作者。
4. 开篇：即将失败的任务，规则错位或试错，翻盘并交付新目标。
5. 章内：按本章功能选用「反差笑点 / 失败推进 / 队伍互损 / 机制升级 / 笑点后钩子」。
6. 成文：句长约 20–30 字，段长约 25–40 字，对白大约一成到两成。笑点必须改局面。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 笑点改变局面
- 失败留下资料
- 每场最多新增一项机制
- 章末有新目标

## 硬约束

- 读者承诺：认真目标与荒诞执行错位，笑点后仍有结果
- 不要只堆梗
- 不要笑完即停
- 区间不是合格线
