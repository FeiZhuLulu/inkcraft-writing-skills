# 历史权谋写作

## 触发条件

项目或用户任务是历史权谋、架空历史、争霸，或明确要求按权谋方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认制度约束、粮饷或军政、身份网络、可衡量目标。缺一项就先问作者。
4. 开篇：身份错位危机，阻力出现，局部结果与反弹。
5. 章内：按本章功能选用「政务反弹 / 资源改革 / 结盟背叛 / 制度嵌入决策 / 大局压力」。
6. 成文：句长约 25–40 字，段长约 40–55 字，对白大约两成上下。制度解释嵌进决策。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 目标可验证
- 反弹改变策略
- 方案有执行成本
- 章末形成下一项政治任务

## 硬约束

- 读者承诺：制度与粮饷是硬约束
- 不要先讲制度史
- 不要让方案免于成本
- 区间不是合格线
