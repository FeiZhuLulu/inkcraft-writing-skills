# 历史权谋写作

## 触发条件

项目或用户任务是历史权谋、架空历史、争霸，或明确要求按历史权谋方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物谱系、历史制度大纲和上一章。以已写正文和作者设定为权威。缺设定时先问，不要随意更改历史物理常识。
2. 判断当前任务：开书设计、前三章、朝堂博弈、军政革新，还是审阅。
3. 开书：确认权谋卖点、初始身份危机、制度与粮饷硬约束、派系格局、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章身份错位造成的具体危机，第2章政务或身份网络产生阻力，第3章局部方案结果与制度性反弹。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「政务目标与反弹 / 资源/改革闭环 / 身份错位开篇 / 结盟与背叛 / 制度解释嵌入决策 / 局部胜利后的大局压力」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见」执行。
6. 成文：句长约 25–40 字，段长约 40–55 字，对白大约两成上下。用程序、物件与利益试探落地时代信息。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 制度、程序与粮饷构成不可逾越的硬约束
- 方案经过严谨的执行成本核算与利益反弹检验
- 对白承担利益试探、要挟与立场博弈
- 章末留下可衡量的下一项政务或军事任务

## 硬约束

- 读者承诺：让制度、粮饷、军政和身份网络成为硬约束；方案必须经过执行成本、利益反弹与责任
- 不要开篇大篇幅背诵王朝两百年兴衰通史
- 不要脱离时代生产力与组织基础盲目机械降神
- 区间不是合格线；制度科普打断政治决断比数字偏离更严重
