# 科幻 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖故障、约束、尺度、开篇、界面、结算，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、如何检查、失败了怎么改。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 技术故障转任务

适用：飞船遇险、设备停转、深空通信中断、赛博义体短路、用硬核工程操作推动剧情。

上场先定：正在报警的具体设备名称与物理故障机制；现场可用的维修工具与操作流程；故障排除后意外引出的全新主线任务。

步骤：

1. 给出具体的设备警报与物理破坏表现（磁约束线圈过载漏磁、冷却水泵轴承卡死、神经义体接口电压击穿）。
2. 主角穿戴防护装备，在极限环境下执行符合工程逻辑的排查与手动检修（如切换旁路电路、手动摇动泄压阀门、切除烧毁的代码模块）。
3. 故障排除后，在分析故障原因或读取黑匣子数据时，发现这并非意外磨损，而是人为破坏或深空异变所致。
4. 将技术故障的解决，顺理成章地转化为下一步必须执行的排查、追凶或远航任务。

纸上必须看见：一个具体的故障仪表读数、一次带有机械质感的手动维修操作、一份带出新任务的故障分析日志。

检查：故障与检修过程是否具备可信的物理/工程逻辑；是否避免了主角敲一下铁皮机器就自动修好的魔幻感。

失败：主角面对主发动机熄火，闭上眼睛用心灵感应或者随便按个按钮就修好了。改法：让主角穿上宇航服出舱，在零下两百度太空中冒着微陨石雨手动更换熔断的超导保险丝。

教学：远航勘探船主重力环突然发出刺耳金属扭曲声，仪表盘红灯狂闪：「三号磁悬浮轴承过热脱轨，重力环将在三分钟内因离心力解体」。主角咬紧牙关，在失重状态下推开检修井铁盖，手持液氮喷枪与重型扭力扳手悬停在飞速旋转的轴承旁。他先用液氮强行冷缩卡死的合金齿轮，在轴承转速降至安全阈值的瞬间，手动扳动液压止锁销！巨响过后，重力环停转保住了船体。然而当他拆开轴承箱时，赫然发现里面卡着一枚被激光熔断的特种钛合金铆钉——有人在起航前蓄意破坏了飞船，凶手就在当前休眠的五名船员之中。

## 任务约束与资源

适用：深空变轨、逃生决断、能源见底、极端资源配给、在物理法则边界内做极限取舍。

上场先定：明确量化的核心任务目标；受限的资源与时间窗口硬指标（工质余量、氧气小时数、变轨引力窗口）；主角在两个必须付出代价的航行方案中做出选择。

步骤：

1. 亮出清晰冰冷的技术账本与死线：反物质推进剂仅剩百分之三、维生系统将在四十分钟后耗尽、距离错过木星引力弹弓窗口只剩九百秒。
2. 摆出两个代价不同的技术航海方案：方案A抛弃全船所有科学勘探样本轻装加速，能保住全员性命但本次航行彻底破产；方案B强行过载聚变炉维持全载重，但有三成概率在引力加速中炉体崩解。
3. 舰桥团队在数据与推演中激烈争论，主角权衡大局，拍板执行，承担全部航海责任。
4. 记录执行后的资源损耗与技术状态改变，绝不中途反悔。

纸上必须看见：精确到小数点的工质/时间数据、两套严谨的轨道方案、一次不可逆的技术决断、一份缩减后的物资清单。

检查：方案是否受到天体力学与热力学定律的硬性约束；取舍是否带来了真实的物质损失。

失败：主角既不减重也不过载，大喊一声「我相信飞船的奇迹」就直接加速冲了过去。改法：严格写出减重操作——将价值数亿的深空矿石样品仓手动弹射入虚空，飞船质量减轻四十吨，才险险在窗口关闭前切入变轨轨道。

教学：深空勘探船遭遇太阳耀斑风暴，护盾发生器功率见底，逃生坐标在三千万公里外的土星空间站。方案A：将剩余百分之五的全部聚变燃料注入离子主引擎全速冲刺，能在风暴追上之前抵达，但抵达时将无燃料减速，只能撞击空间站自毁；方案B：关闭所有船舱照明、重力与空气加热系统，全员穿宇航服进入低温休眠，仅靠辅助冷气喷口进行惯性漂流，能保住飞船但休眠者有两成脑死亡风险。主角作为舰长，亲手切断了全舰供暖电闸，下达全员休眠指令：「把命交给惯性定律，土星见。」

## 文明尺度逐层揭示

适用：星际文明接触、发现外星巨构、静默猎杀假说被实测坐实、从微观个体逐步窥见宏大宇宙图景。

上场先定：从小处着手的初始观测数据或外星造物碎片；通过两次以上可验证的科学实测逐步放大尺度；避免一次性倾倒世界观百科。

步骤：

1. 从微观可操作的设备异常或奇特物质切入：一艘看似普通的废弃卫星残骸、一段夹杂在宇宙背景辐射中的周期性脉冲。
2. 主角团队通过光谱分析、碳十四测年或量子干涉实验，逐步推翻常规假说，证明该物质具有超越人类物理认知的特征（如绝对零度下依然具备超导流动性、晶格在红外波段完全吸光且简并态锁死）。
3. 将微观特征连接到星际文明尺度的宏大推演：这不是自然天体，而是一件跨越十亿年的战争武器残片。
4. 宏大揭示震撼人心的同时，给主角和人类文明留下迫在眉睫的技术防御命题。

纸上必须看见：一个具体可触摸的微观标本、两道严谨的实验检测数据、一个呈指数级放大的文明图景。

检查：文明尺度的展开是否依靠扎实的科学证据链条步步推导；是否保留了对广袤宇宙的敬畏感。

失败：主角捡到一块外星石头，石头突然开口说话，把银河系三千万年的星际战争史一股脑全讲了出来。改法：让科学家团队在射电天文台连续观测三年，通过引力透镜效应推算出太阳系边缘正在被一层无形的曲率泡所包裹。

教学：深空勘探队在小行星带捕获了一枚边长四十厘米的黑色六棱晶柱。第一轮扫描：红外波段被完全吸光，表面却测不到可分辨的晶界；第二轮激光热切割测试：三万度高能激光照射十秒，晶柱温度未发生可记录变化，内部密度读数落在简并态区间。首席科学家丢掉实验报告：「这不是陨石，这是一块被压到恒星核心密度的动能弹头残片……制造它的文明，能把一颗行星当靶场。」微观标本的测试，瞬间把人类舰队从勘探任务推到轨道防御死线。

## 技术异常开篇

适用：开书第一章、深空惊悚、赛博觉醒、在未知技术异象中建立第一重悬念。

上场先定：主角正在监控的具体科学仪器与日常工作场景；一处绝对违背常规天体物理的硬核技术异常；必须采取的第一次应急自救或报告动作。

步骤：

1. 建立逼真的科研或深空作业日常：在射电天文台记录脉冲星数据、在近地轨道空间站进行舱外焊接。
2. 监控终端突然捕捉到颠覆认知的数据异常：原本恒定闪烁的脉冲星突然同时熄灭、雷达显示正前方的虚无太空中出现了一个负质量引力陷阱。
3. 主角经过反复校准排除了仪器硬件故障，确认宇宙正在发生不可逆的物理法则畸变。
4. 紧急拉响最高级别警报，并在系统彻底宕机前完成数据备份与逃生锁定。

纸上必须看见：一个真实严谨的工作环境、一组颠覆物理常识的异常数据、一次果断的应急处置。

检查：技术异常是否可复核、符合科幻硬逻辑；开篇是否迅速建立了巨大的悬念张力。

失败：开篇第一章全在写主角的日常生活琐事，直到第三千字还没有任何科幻要素登场。改法：第一段第一句直接写「射电望远镜的阵列荧光屏上，巴纳德星方向的信号波形毫无预兆地变成了一条死寂的直线」。

教学：南极深埋地下的中微子探测实验室内，警报声刺破了极夜的死寂。值班工程师主角揉着布满血丝的眼睛看向主控终端：原本每秒只捕获三到五个中微子的超纯水光电倍增管阵列，此刻正以每秒数亿次的高频疯狂闪烁！数据曲线不是钟形分布，而是被人工编码成了一串不断重复的斐波那契数列。主角一把抓起红色紧急电话拨通国家天文台，声音颤抖：「排除所有设备误报，有高能中微子束正在从织女星方向直射地球核心……这不是自然现象，这是外星文明定向发射的引力坍缩指令！」

## 界面/设备动作化

适用：舰桥指挥、人机脑桥超频、战机缠斗、复杂的赛博黑客攻防、让硬科幻操作生动可视化。

上场先定：主角正在操作的具体人机交互界面（HUD战术目镜、神经接入插头、全息操控球）；必须手动输入的关键技术参数；参数变化直接引发的物理动作反馈。

步骤：

1. 详细描写人机交互的界面细节与生理感官反馈：战术目镜上跳动的红绿向量箭头、神经插口接入时脊髓传来的冰冷刺痛。
2. 主角在极度危急的对抗中，手动推拉操纵杆、精准输入复杂的动力学参数或绕过防火墙代码。
3. 界面读数的变化，立即转化为飞船喷射工质、武器系统过载或无人机群阵形重组的剧烈物理破坏。
4. 战后展示设备过热与人体生理神经的超负荷损耗。

纸上必须看见：清晰的界面投影与读数、一次带有肌肉记忆的操作指令、一次立竿见影的武器/动力反馈。

检查：操作过程是否将抽象的代码与数据转化为具有冲击力的视觉动作；是否避免了毫无细节的「主角一顿敲键盘」。

失败：主角在电脑前按了几次回车键，敌方整个庞大的舰队就全部瘫痪了。改法：写出主角通过眼球追踪锁定敌方雷达扫描盲区，手指连续按下十二个超频跳闸阀门，将动力全部灌注进单侧矢量喷口的硬核操作。

教学：主角将神经传导贴片重重按在后颈接口，视野瞬间被铺天盖地的全息数据流覆盖。敌方三架重型截击机在雷达上以音速逼近，锁定警报震耳欲聋。主角右手猛推主引擎节流阀，左手在全息光标上飞速滑动，将主火控系统的算力全部重定向至前置近防炮：「关闭自动瞄准，重载弹道偏转补偿算法，偏置角：正三点二度！」他按下扳机，双管电磁炮以每秒两千发的高速向虚空中喷吐火舌，迎面冲来的敌机正好撞在提前算好的弹幕截面上，在太空中凌空炸成一团寂静膨胀的耀眼火球！

## 任务结算与更大问题

适用：击退外星舰队、完成深空跳跃、攻破赛博母体、阶段性大结案、引出更深层宇宙危机。

上场先定：本场彻底兑现的技术成果与逃生胜利；在解开旧谜题的同时意外暴露出的更大宇宙风险；新危机如何写成下一阶段的任务目标。

步骤：

1. 实打实兑现一项硬核的技术胜利（成功点火曲率引擎跳出黑洞引力圈、成功在母舰核心植入杀毒代码）。
2. 在全员欢呼胜利的刹那，仪器终端解析出了战利品背后的绝望真相（敌方舰队只是逃难的难民船，真正的毁灭者正在整个银河系推行维度清理）。
3. 胜利带来的不是安宁，而是人类文明被正式推入更残酷的星际博弈舞台。
4. 章末把大局危机转化为下一阶段必须执行的技术攻关或远征任务。

纸上必须看见：一个确凿的技术胜利终点、一份冰冷的深空新情报、一个指向未知星域的远征坐标。

检查：局部成果是否真实交付；新危机是否由本次技术行动的底层因果推导而来。

失败：打完胜仗后全舰官兵开香槟庆祝，全书大团圆完结，完全丧失了科幻的深邃感。改法：飞船刚跃迁至安全星域，射电望远镜便观测到身后的整个猎户座悬臂正在被抽成一条引力细线，恒星一颗接一颗熄灭。

教学：曲率引擎成功爆发出一道耀眼的蓝白光环，飞船在时空涟漪中瞬间完成了三十光年的超空间跳跃，险险脱离了吞噬恒星的引力黑洞。舰桥内响起雷鸣般的欢呼声，船员们相拥而泣。然而主控AI突然在全息屏幕上投影出一道来自三十光年外的空间破裂回波：「警报，追踪到高维引力坍缩波正在以超光速蔓延，被我们引爆的黑洞不仅没有消亡，反而激活了上古文明遗留的银河系‘大撕裂’防御链条。」雷达图上，半个悬臂的恒星都在相继闪烁熄灭。主角站在舷窗前，凝视着黑暗冰冷的深空，缓缓戴上航天头盔：「传令全舰，启动‘播种计划’，我们不能回地球了，必须前往仙女座星系建立新家园。」
