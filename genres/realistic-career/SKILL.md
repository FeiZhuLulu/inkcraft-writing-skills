# 现实职场写作

## 触发条件

项目或用户任务是现实、职业文、职场、年代文，或明确要求按现实职场方法写、改、审章节。

## 执行步骤

1. 先读项目设定、行业规程、专业参数表和上一章。以已写正文和作者设定为权威。缺设定时先问，不要随意打破行业客观规律。
2. 判断当前任务：开书设计、前三章、专业破局、责任担当，还是审阅。
3. 开书：确认职业卖点、初始业务困境、专业规程与底线、组织生态、前三章承诺、本卷两道门槛。展开读 `01-structure.md`。
4. 开篇：第1章流程被现实打断的具体工作任务，第2章现场事实与制度形成阻力，第3章专业判断改变结果并留下新责任。展开读 `02-opening.md`。
5. 章内：按本章功能只选一种主写法：「职业案件闭环 / 专业判断与责任 / 制度与现实权衡 / 工作任务开篇 / 工具细节服务决策 / 完成任务后的新责任」。展开读 `03-methods.md` 对应节，按「上场先定 → 步骤 → 纸上必须看见」执行。
6. 成文：句长约 25–35 字，段长约 35–50 字，对白大约两成上下。用动作、工具与流程承载职业信息，先写现场后果再补专业解释。展开读 `04-prose.md`。
7. 写完用 `05-checklist.md` 核对。勾不上的项回到对应写法改。若环境能改文件，先给作者看修改再写入。

只拷本文件也能工作。同目录 `01`–`05` 是展开，不是前提；写具体场时优先打开对应节。

## 成功标准

- 专业流程与工具器械具备真实的行业可信度
- 专业判断完全依托现场客观数据与物理证据
- 角色在制度合规与现实抢救之间做出带担当的权衡
- 章末留下可量化的下一项工作指标或交班死线

## 硬约束

- 读者承诺：让专业流程、组织协作和现实资源构成硬约束；成长体现为判断、责任和可复用的工作方法
- 不要把职业文写成悬浮的谈恋爱背景板
- 不要违背基础的医学、法学或工程学科学常识
- 区间不是合格线；术语清单报菜名打断抢修救治比数字偏离更严重
