# 现实职场 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖案件、责任、制度、开篇、工具、收尾，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、本场计数、如何检查、失败了怎么改。本场计数只翻译该写法原有的量化控制，不另造数字。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 职业案件闭环

适用：急诊抢救、刑侦现场勘查、重大设备抢修、重大诉讼开庭、完成一个阶段性专业项目。

上场先定：明确的专业任务与标准化规程；现场突发的复杂变量或严重干扰；主角依托扎实证据链进行的精准决策；现场指标好转的客观验收结果。

步骤：

1. 明确当前专业工作的标准作业程序与客观考核指标（如必须在十分钟内建立两条静脉通路并止血、必须在暴雨前提取完现场全部轮胎压痕）。
2. 用突发的复杂物理或生理事实打破常规（如患者血管塌陷无法静脉穿刺、机床在高速切削时产生异常高频啸叫）。
3. 主角凭借扎实的理论基本功与丰富的经验，迅速调整战术，完成超高难度的精准操作。
4. 现场指标恢复正常，数据达到验收标准，完成专业案件的成功闭环。

纸上必须看见：一份清晰的操作流程表、一次棘手的突发干扰、一组恢复正常的监护仪/仪表数据、一份签字确认的交接单。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 可观察的工作流程步骤至少 2
- 专业判断必须依据现场事实

检查：流程与解决手法是否经得起行业专业知识推敲；是否避免了毫无细节的玄学秒杀。

失败：主角不用任何医疗器械，随便在病人心脏上按两下，病人就从死亡线上奇迹复活。改法：写出主角使用骨髓腔穿刺枪，在患者胫骨结节下两指处精准进针建立骨髓输液通道，五百毫升林格氏液在两分钟内快速加压滴入，血压回升至90/60mmHg。

教学：急诊创伤抢救室内，车祸休克患者四肢大面积烧伤，外周静脉全线塌陷，护士连续两次深静脉穿刺失败，监护仪上的脉搏已微弱至每分钟三十次。主角神色沉稳戴上无菌手套，抓起一把骨髓穿刺针与利多卡因，在患者左侧胫骨结节下方两厘米平坦处迅速定位。进针、突破骨皮质落空感传来、回抽见暗红骨髓血、连接加压输液管一气呵成！三分钟内一千毫升代血浆强行灌入，患者心率稳步回升至八十，瞳孔对光反射恢复。主角摘下沾血的手套，在抢救记录单上利落地签下自己的名字。

## 专业判断与责任

适用：专家会诊、重大技术方案论证、法庭激辩、在多方分歧中坚持正确主张并主动担责。

上场先定：摆在桌上的两种截然相反的专业判断方案；误判可能导致的严重法律或人命代价；主角如何用无可辩驳的数据说话并主动签署连带责任书。

步骤：

1. 列出各方专家依据常规经验给出的保守方案（如保守用药维持），以及主角提出的激进但唯一能根治的方案（如立即开胸探查）。
2. 严肃说明该判断的极高风险与一旦失败必须承担的法律或职业处分后果。
3. 主角出示现场抓取的关键物理证据或化验异常箭头，彻底推翻保守推论。
4. 主角当众在《风险知情同意书》与《责任承诺书》上签字，承担全部决断责任并立即主持实施。

纸上必须看见：两份针锋相对的专业意见、一张带有异常箭头的客观报告单、主角在责任书上力透纸背的签名。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 互斥方案至少 2
- 可追踪责任至少 1

检查：主角的判断是否完全依托客观物理事实而非主观臆测；是否展现了崇高的职业伦理与敢于担当的脊梁。

失败：主角提出方案后，领导和家属毫无疑虑地全力支持，没有任何风险与责任权衡。改法：让科室主任拍桌子警告主角「一旦死在台上，你的医师执照这辈子就吊销了」，主角神色自若地递上自己早已写好的辞职免责声明。

教学：联合会诊室内，心内科主任主张患者是急性心梗，要求立刻送导管室做冠脉造影放支架；主角身为年轻住院医，拿着刚出来的胸部增强CT与心电图大步走入，沉声打断：「绝对不能放支架！心电图虽然ST段抬高，但患者双上肢收缩压差超过三十毫米汞柱，CT显示升主动脉根部存在撕裂内膜片——这是最凶险的A型主动脉夹层！如果按心梗注射抗凝药造影，主动脉会在导管进去的瞬间破裂猝死！」全场死寂。心内科主任脸色铁青，主角拉过病历夹，刷刷签下名字：「如果判断错误，所有医疗事故责任由我一人承担，现在必须立即急诊开胸！」

## 制度与现实权衡

适用：医疗合规审查、工程安全与工期冲突、司法程序正义与实体正义冲突、职业道德两难。

上场先定：冷冰冰的行政制度红线要求；眼前迫在眉睫的生命或财产毁灭危险；角色在合规死守与违规救场之间的痛苦抉择与组织后果。

步骤：

1. 写清不可动摇的制度条例（如无直系亲属签字不得实施四级手术、未获审批不得擅自更改高压管线走向）。
2. 突发极端现实险情，如果死板等待程序走完，人必死无疑或工厂必毁于一旦。
3. 主角在理性权衡后，毅然选择打破繁琐程序先行救场，同时做好接受组织纪律处分的全部准备。
4. 救场成功后，坦然面对行政医务处或纪检部门的严肃调查与问询。

纸上必须看见：一条白纸黑字的严苛管理条例、一个倒计时的生死绝境、一次带担当的破规操作、一场严肃的战后审查记录。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 制度要求至少 1
- 钱粮、兵员或工期等物质约束至少 1

检查：制度与现实的冲突是否真实存在于行业痛点之中；是否避免了将规章制度简单抹黑为反派工具。

失败：主角随便违反任何制度，院领导不仅不处分，还大肆宣扬表彰，完全无视现代法治与制度规范。改法：主角虽然成功救活了病人，但因违规操作依然被医务处通报批评、扣除当月奖金，但在全科室赢得了最真挚的敬意。

教学：深夜暴雨，一名无名氏流浪汉因颅脑外伤大出血被送到急诊，瞳孔散大，脑疝形成。按照医院规定，无亲属签字且无身份信息的患者，实施开颅手术必须报备医务处并由分管院长签字审批，但此时审批电话占线，距离脑死亡只剩五分钟。主角看着心电监护仪不断下滑的呼吸频率，一把推开审批单，按下了手术室急救铃：「不能等了，推去一号手术间！按《民法典》紧急避险条款处理，所有行政违规处分我一个人担！」开颅手术成功保住了生命，次日清晨，医务处在全院早会上宣布：林澈因违规越级操作扣除绩效两千元，但鉴于挽救生命有功，授予院级‘优秀医务工作者’提名。

## 工作任务开篇

适用：开书第一章、急诊夜班、新入职突发大案、接手重大烂摊子工程、用快节奏业务迅速建立主角专业形象。

上场先定：主角开局正在处理的具体棘手工作；被突发意外打破的常规流程；主角动用专业绝活完成的初次惊艳救场。

步骤：

1. 开篇第一句直接切入充满行业烟火气与机械声的业务现场（监护仪报警、车床轰鸣、翻阅卷宗的沙沙声）。
2. 一场极具压迫感、看似必败的业务事故突发，周围同事手足无措。
3. 主角在混乱中接管指挥，凭借令人惊叹的手法与冷静的逻辑，在最短时间内拆除引信。
4. 救场虽然成功，但意外暴露出主角当前面临的职场被打压或边缘化窘境。

纸上必须看见：一个专业术语精准的业务现场、一次紧张刺激的拆弹式操作、一次全场愕然的逆转、一份写满现实压力的处分/考核通知。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 被流程打断的具体任务至少 1
- 职业成长问题至少 1

检查：第一章是否在展现过硬专业功底的同时，迅速拉起职场矛盾冲突。

失败：第一章全在写主角身世有多惨、大学成绩有多好，主角一直在自怨自艾没有任何行动。改法：第一句直接写「监护仪发出刺耳的长鸣，刚送进来的服毒患者嘴角开始喷涌白色血沫，胃管被咬断在食道内」。

教学：凌晨两点半的急诊外科清创室，主角刚给一个醉酒患者缝合完眉弓，走廊外突然传来撕心裂肺的呼救声。一名三岁幼童误吞了一枚一元硬币，硬币卡在声门上方，呼吸完全衰竭，面色青紫四肢抽搐，值班规培医生的喉镜根本插不进去。主角扔下缝合线冲出清创室，甚至来不及戴手套，一手扣住幼童下颌使其头部后仰，一手精准握拳抵住幼童剑突下方，行云流水般施展海姆立克急救法连续三次向上冲击，同时右手食指如电般探入咽喉——当啷一声脆响，沾着血沫的硬币飞出落在瓷砖地面上，幼童哇的一声大哭出声！护士们瘫坐在地，而门外，主角收到了一条调令短信：由于得罪副院长侄子，明日起调往偏远社区卫生服务站。

## 工具细节服务决策

适用：手术器械操作、精密仪器排查、痕检物证提取、图纸修改、让专业细节成为推动剧情的核心载体。

上场先定：主角手中握着的具体工具或设备型号；只解释当前决策必须知道的关键工艺或技术参数；工具动作如何直接决定了事件走向。

步骤：

1. 精准描写专业工具的物理质感、握持手感与操作细节（如十一号尖刀片的角度、扭矩扳手的刻度线、显微镜下的微观分层）。
2. 结合工具参数，只给出当前决策所必须的那句关键行业原理（如「钛夹在此处闭合若超过三毫米就会撕裂伴行静脉」）。
3. 主角凭借教科书级的手法，完成毫厘之间的精准操作，避开致命雷区。
4. 工具动作完成后，现场危机迎刃而解，展现工匠级的大师风范。

纸上必须看见：具体的工具器械名称、一次微观层面的毫厘操作、一次立竿见影的物理反馈。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 服务当前决策的工具或流程细节至少 1
- 决策变化至少 1

检查：工具细节是否真实服务于当前情节与生死决策；是否避免了枯燥的器械报菜名。

失败：主角做手术全篇只有一句「他拿起手术刀开始切除，手术非常顺利」。改法：详细写出主角使用超声骨刀在距离脊髓神经仅0.5毫米的椎板上进行毫米级磨削，骨屑在生理盐水冲洗下无声飞溅，脊髓搏动完好无损。

教学：无影灯下，患者颈动脉瘤已薄如蝉翼，随时可能破裂引发颅内大出血。主刀医生手心冒汗无法下刀，主角接过一把精细显微剪与双极电凝镊。他将手术放大镜倍率调至八倍，左手无名指抵在患者下颌骨形成绝对稳定的三角支撑，右手持尖头解剖剪在颈动脉鞘薄如蝉翼的筋膜层间以0.1毫米的行程轻巧剥离。「双极电凝，功率降至八瓦，踩踏间歇半秒。」主角声音低沉如冰，电凝镊尖端轻触破损血管边缘，滋的一声微响，白烟散去，微型钛夹在破口处精准闭合！跳动的血肿瞬间瘪了下去，监护仪上的颅内压波形彻底回稳。巡回护士长长舒了一口气：「这手剥离功夫，全院找不出第二个人。」

## 完成任务后的新责任

适用：手术大获全胜、疑难大案告破、重大设备成功试车、破格晋升、引出更高阶的行业攻关。

上场先定：本场彻底兑现的业务大胜与阶段性表彰；因本次成功而赢得的行业声誉与实质职权；随之而来的国家级或重大疑难新课题。

步骤：

1. 彻底解决眼前的局部危机，兑现清晰的战果（患者康复出院家属送锦旗、破获连环大案受到公安部嘉奖、设备通过国际ISO验收）。
2. 院领导或行业泰斗在全科早会上正式宣布主角的晋升任命或破格立功受奖。
3. 庆功之余，领导将一份关乎行业生死存亡的绝密国家级攻关项目或高危课题交到主角手中。
4. 章末把荣誉转化为下一阶段必须全力以赴的沉重行业使命感。

纸上必须看见：一面沉甸甸的锦旗/荣誉证书、一份破格晋升的正式红头文件、一份写满技术难题的新课题任务书。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 局部结果至少 1
- 更高层责任至少 1

检查：局部成果是否实打实交到主角手中；新责任是否展现了现实行业人物不断攀登高峰的职业担当。

失败：救完人之后大家吃顿饭全书大团圆完结，完全没有体现出医学或科学探索的无止境追求。改法：主角刚走出手术室，院长便推开门递上一份调令：国家医疗救援队即将启程前往重大疫情前线，指名要求主角担任首席急救专家。

教学：全院早交班大厅内，院长亲自宣读通报嘉奖：「鉴于林澈医生在昨夜特大创伤抢救中展现出的超凡专业能力与担当，经院党委研究决定，破格提前结束其规培期，任命为主治医师，兼任急诊创伤中心副组长！」雷鸣般的掌声响彻大厅，曾经刁难他的副院长面色铁青却不得不跟着鼓掌。散会后，院长将林澈叫进办公室，拉开抽屉取出一份红头绝密文件：「小林，别急着高兴。省里刚刚确诊了三例来源不明的严重肺部感染坏死病例，现存抗生素全部耐药，省卫健委成立了紧急攻坚专家组，我要你代表我们医院挂帅出征，敢不敢接？」林澈立正敬礼，接过文件：「保证完成任务！」
