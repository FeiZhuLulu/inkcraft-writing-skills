# 洪荒写作

## 触发条件

项目或用户任务是洪荒、封神、神话流，或明确要求按洪荒方法写、改、审章节。

## 执行步骤

1. 先读项目设定、人物、大纲和上一章。以已写正文和作者设定为权威。
2. 判断当前任务：开书设计、前三章、章内推进，还是审阅。
3. 开书：确认神话秩序、因果、阵营约束、前三章避祸承诺。缺一项就先问作者。
4. 开篇：身边的避祸动作，秩序后果，试探或债务。
5. 章内：按本章功能选用「因果显形 / 阵营站队 / 稳健试探 / 神话交易 / 大劫钩子」。
6. 成文：句长约 35–50 字，段长约 40–55 字，对白大约一成到两成。神话规则用仪式或结果显形。
7. 写完用自检表核对。若环境能改文件，先给作者看修改再写入。

需要展开时可读同目录 `01`–`05`。不要求先读完再动手。

## 成功标准

- 规则通过结果出现
- 站队留下约束
- 人物局限仍在
- 代价持续到下一场

## 硬约束

- 读者承诺：在神话秩序里用试探和代价改变命数
- 不要把猜测写成天道事实
- 不要让交易代价当场清零
- 区间不是合格线
