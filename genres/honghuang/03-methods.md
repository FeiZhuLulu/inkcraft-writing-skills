# 洪荒 · 场景写法

写章前先看细纲里这场戏的功能，只选一种主写法。可以在边角带一点别的元素，但主轴绝不要混淆。六种写法覆盖因果、阵营、尺度、试探、交易、回报，不要求一章六种都用。

每种写法都按统一结构呈现：何时适用、上场先定什么、步骤怎么走、纸上必须看见什么、本场计数、如何检查、失败了怎么改。本场计数只翻译该写法原有的量化控制，不另造数字。教学例子均为虚构情境，用来说明操作逻辑，不要当成题材模板去机械套用。

## 因果规则显形

适用：天道因果降临、业力缠身、杀伐大劫开启、旧恩怨被天道翻旧账、展现不可违逆的神话铁律。

上场先定：主角正在执行的避祸或谋划动作；天道因果通过何种仪式、法器异象或业力反噬显化；留下哪一项无法免费绕开的因果债务。

步骤：

1. 从具体的避祸或谋划动作切入：封山闭关、炼制遮蔽天机的灵宝、推演量劫死线。
2. 让天道规则通过具体的仪式、异宝反噬或天象降临显形：因果红线显化缠绕在元神之上、杀戮过多导致头顶现出三尺业火劫云。
3. 展现触碰因果后的严酷惩戒：道心蒙尘、突破时天魔来袭、或被仇家大能凭借因果牵引精准定位。
4. 迫使主角付出实质代价（消耗功德金光、舍弃本命灵物、立下天道誓言）以化解或转嫁因果。

纸上必须看见：一个避祸动作、一次天道因果显形的具象化异象、一笔确凿记在元神上的因果账单。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 可观察显形的规则至少 1
- 不可免费绕开的因果代价至少 1

检查：因果规则是否切实影响了角色的行动决策；因果代价在后续章节中是否持续可追踪。

失败：主角杀人夺宝随心所欲，嘴上喊着不怕因果，天道也毫无反应，把洪荒写成了普通无脑爽文。改法：杀完大能后，让天道降下一道因果神雷击毁他的护山大阵，逼他必须拿出积攒百年的功德金光去消弭业障。

教学：他刚在密室中将夺来的后天灵宝抹去神识烙印，虚空中突然浮现出一根带血的因果红线，直接扎入他的元神深处。头顶三尺处劫气翻滚，洞府外的古树瞬间枯萎焦黑——原宝主乃是截教赵公明的记名弟子，此宝一动，杀劫因果已定。他脸色剧变，不得不立刻割舍三成功德金莲包裹红线，强行将因果转嫁到事先炼制好的一具替身白玉傀儡之上。傀儡替他挡了死劫碎成齑粉，但他必须在天亮前将残骸彻底沉入九幽冥海，否则三日内必有截教金仙杀上门来。

## 阵营与道统站队

适用：阐截相争、巫妖对峙、天庭招安、西方教度化、面对各方大能逼迫必须表明立场。

上场先定：两大对立阵营的核心利益与致命冲突；主角如何通过言语礼数、利益试探或明拒暗合进行表态；站队后带来的实质保护与沉重约束。

步骤：

1. 列出两大或多方阵营摆在台面上的利益诱惑与背后的杀机：入阐教可享正统道场庇护但受清规戒律严控，入截教有万仙来投的威势却难逃量劫封神杀劫。
2. 让主角在各方使者面前，运用古老神话礼数、隐秘信息差与利益捆绑进行高段位周旋。
3. 主角做出审慎的站队或秘密结盟表态，绝不把话说满，同时留好退路。
4. 记录站队后的双重后果：获得了一件阵营信物或气运加持，但也立刻被敌对阵营列入必杀名单。

纸上必须看见：冲突分明的阵营利益、一次高水平的神话谈判、一个代表立场的信物、一份全新的阵营敌友名单。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 阵营至少 2
- 站队后的保护或约束至少 1

检查：阵营之间是否存在不可调和的根本利益冲突；站队后主角的行动边界与安全状态是否发生实质变化。

失败：主角把所有教派的大能当成傻子耍，左右通吃毫无代价，所有圣人都抢着跪求收他为徒。改法：让他在两教使者面前被迫立下神魂誓约，虽然拿到了一颗九转金丹，但也必须承诺在大劫中替该教出战一次。

教学：正统教门白衣执事与海外散修黑袍说客同时降临洞府。阐教许诺赐下一柄拂尘收为外门执事，但要他交出山门地脉供正统布阵；截教许诺称兄道弟共享气运，却要他随军征讨西土诸侯。主角躬身向两方大能行道家至高大礼，言辞滴水不漏：「弟子福薄缘浅，不敢贪天之功。愿献上东海灵珠三颗助正统布阵，同时愿为散修道友提供避劫丹药十瓶。」各退一步，送走两尊大佛，但他手腕上已同时留下了阐教的玉符印记与截教的穿心锁感应——大劫之中，他必须在这两根悬崖钢丝上如履薄冰。

## 神话尺度压到身边

适用：开书、黄金三章、大劫序幕拉开、天道圣人争锋、需要将宏大无垠的洪荒伟力精准压在小人物的生死线上。

上场先定：主角身边最微小的日常或避祸目标；千里之外神话大能斗法引发的局部毁灭性后果；大劫压迫如何逼出主角的下一步求生动作。

步骤：

1. 从极具生活质感的小仙日常或闭关动作入场：喂养灵禽、修补蒲团、清点库房中的避雷灵符。
2. 迅速将千里外甚至九天之上的神话争斗余波，以毁灭性的物理事实砸在主角身边：巫妖大战的断矛从天而降砸裂主峰、大能交手的余波瞬间蒸发整条大河。
3. 主角凭借精密严谨的避险机关与保命底牌，在天地倾覆中险死还生。
4. 将身边的局部灾劫与整个洪荒的量劫大势严密咬合，留下不可拖延的逃生或转场任务。

纸上必须看见：一件细小的日常动作、一次神话级伟力的毁灭性降临、主角的一张硬核避险底牌、一个被彻底打碎的旧环境。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 神话秩序后果最晚第 3 章交付
- 必须留下可执行收束问题

检查：神话事实是否外人可验证、具有恐怖的物理破坏力；主角是否保持了凡人/小仙的清醒认知局限。

失败：开篇又是大段旁白讲解洪荒有多大、圣人有多强，主角却像个旁观者在看戏。改法：直接让大妖交战的一滴余毒黑血滴在主角的护山阵眼上，逼主角在十息之内做出弃山决断。

教学：他正坐在蒲团上用灵泉水研磨朱砂绘制清心符。万里之外的天穹骤然撕裂出一道万里血痕，太一的混沌钟声跨越虚空震响，钟波扫过，他洞府所在的整座青峰瞬间被拦腰震碎成漫天石粉！护山三十六重隐匿阵连一息都没能撑住便灰飞烟灭。他在千钧一发之际捏碎九地遁空符，本尊顺着事先挖好的万丈地道滑入地底暗河，头顶已化作一片被妖火焚烧的赤地——大劫的齿轮转动了，原本安稳的隐居地彻底报废，今夜必须横渡东海前往三仙岛避难。

## 稳健试探与信息差

适用：探索远古洞天、试探大能态度、测试法宝威能、设局反杀强敌、极致稳健流推演。

上场先定：主角绝对不亲自涉险的前提保障（分身、替身傀儡、神识寄生）；本次试探只验证的唯一关键信息；预设好的三套安全撤退方案。

步骤：

1. 先确保本尊处于绝对安全的防御腹地，派出一具气息完全一致的纸人分身或傀儡携宝出动。
2. 在目标区域只测试一个核心变量（如试探某处阵法是否真有圣人神识留存、试探来袭修士是否身怀剧毒）。
3. 记录试探得出的硬核信息，一旦遭遇危险，果断引爆分身与现场所有痕迹，绝不恋战。
4. 本尊在暗处根据试探反馈，调整最终方案，完成绝杀或避开死局。

纸上必须看见：本尊的安全防线、分身的试探动作、一次果断的断尾自爆、一份带回本尊案头的新情报。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 每次只测试 1 个变量
- 必须有真实退路

检查：测试过程是否具有严密的逻辑推演；主角是否坚决保留了不可动摇的退路。

失败：主角嘴上说着稳健，结果遇到挑衅直接本尊提剑冲上去肉搏。改法：让本尊继续在千里外喝茶，冲上去挨打的只是涂了金粉的机关木人偶。

教学：前方古洞疑似藏有九品净业青莲，但四周煞气弥漫。主角本尊盘坐在百里外的地下密室，手中牵着一根无形神念丝线，操控着一具与自己气息毫无二致的七品莲花分身踏入洞口。分身刚触碰禁制，洞顶猛然劈落一道九霄神雷，将分身当场轰成青烟，神雷中赫然带着正统教门独有的雷法道韵！「果然是钓鱼的杀局，阐教金仙在里面设伏！」主角面无表情地掐断神念线，顺手将地下密室的自毁符箓引燃，本尊已悄然从另一处传送阵遁走万里之外。

## 神话交易与代价

适用：向大能求宝、与龙族/巫族交易资源、谋求天道功德、祈求圣人庇护、以宝换命。

上场先定：主角渴求的核心利益（功德、灵根、避劫玉符）；必须付出的沉重神话代价（气运剥离、许诺因果、交出至宝）；代价在神话秩序中如何持续生效。

步骤：

1. 明确写出交易双方的迫切诉求与实力悬殊，主角必须拿出对方无法拒绝的稀缺筹码（如未来的量劫推演天机、特制疗伤圣丹）。
2. 在平等的道友礼数或契约仪式下完成资源交割。
3. 明确记录主角付出的实质代价：损耗自身三成气运、发下若违此誓身死道消的血誓。
4. 让交易产生的因果在后续剧情中持续发酵，成为推动下一卷大事件的导火索。

纸上必须看见：具体的交易物清册、严苛的神话契约条款、一次不可逆的代价支付、留在天道账本上的长期印记。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 明确的交换至少 1
- 持续存在的代价至少 1

检查：交易是否切实改变了双方的实力平衡；主角付出的代价是否真实保留在后续篇章中。

失败：主角用几句凡俗烂梗就从圣人手里骗走先天至宝，把神话大能写成弱智提款机。改法：必须让主角拿出一件能帮对方门下弟子避开封神杀劫的绝密天机，才能换得对方一次出手机会。

教学：主角在东海龙宫深处与龙王对坐。龙王急需海量天道功德洗刷龙族万古业力，主角开出条件：传授龙族三篇《度人安魂经》并在人间立庙行雨以聚功德，换取龙宫镇海之宝定海神珠一颗。定海神珠到手，宝光耀眼，但天道感应降临，主角头顶的气运长河被硬生生分润了一成注入东海——他帮龙族背负了部分业力，从此龙族的兴衰杀劫与他彻底绑定，若龙族在封神中受创，他也必遭气运反噬。

## 大劫前的局部回报

适用：避过一次灭顶杀劫、谋夺一道天地功德、分赃先天灵宝、收服上古异兽、卷末大胜利。

上场先定：本场实打实兑现的局部胜利成果；因这场胜利而骤然升级的洪荒大势压迫；新压力如何写成下一场的具体布局目标。

步骤：

1. 彻底解决一个局部的生存危机或斩杀强敌，兑现丰厚回报（获得数万丈功德金光、成功将后天灵宝晋升为后天至宝）。
2. 胜利的刹那，立刻揭示出这仅仅是大劫冰山一角：杀死的敌人只是大能棋盘上的一枚弃子，更大的量劫风暴正在天际汇聚。
3. 将宏大的天命压力，转化为下一场必须立刻去加固洞府或寻找新盟友的可执行动作。

纸上必须看见：实质性的宝物/功德入账、更大天劫异象的显现、下一阶段迫在眉睫的避劫计划。

本场计数（只翻译该写法原有的量化控制，不是成文合格线）：

- 局部回报至少 1
- 更大的天命或大劫压力至少 1

检查：局部回报是否真实交付到主角手中；大局压力是否源于既有的因果推演而非凭空捏造。

失败：拿到法宝后全篇完结式地宣布天下无敌，完全无视即将到来的封神或巫妖大劫。改法：法宝炼化的瞬间，天边升起了代表圣人动怒的紫气东来三万里异象，逼主角刚收工就得开始谋划下一道保命防线。

教学：他凭借大阵与替身傀儡，终于将追杀百年的九头凶怪彻底炼化成飞灰，天道感应降下亩许大小的玄黄功德金云，全数灌入他的本命灵剑之中，神剑淬炼出第一道功德圣光，诸邪辟易！然而功德入体的一瞬，他神识中的推演罗盘咔嚓巨响，显化出九重天外的浩瀚棋局——九头怪不过是妖皇为了试探人族底线扔出的诱饵，妖族三百万大军已从天庭开拔，巫妖决战的血雨明日便将淹没洪荒大地。回报是功德神剑大成，新压力是毁天灭地的量劫已在眼前，今夜必须带领部落迁入不周山地宫。
