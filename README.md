# InkCraft 写作方法库

这是一套长篇网文的体裁写作方法：结构、开篇、场景写法和成文节奏。
它不是 InkCraft 软件，也不包含小说原文。

## 包含哪些体裁

玄幻、仙侠、洪荒、都市超凡、末世、无限流、历史权谋、悬疑惊悚、科幻、游戏轻喜剧、都市言情、古言、现实职场。

从 [`genres/README.md`](./genres/README.md) 选体裁。`01` 到 `05` 是工作手册：写细纲看结构，写一场戏看场景写法，不要只扫标题。

## 给 Agent 用

把对应 `SKILL.md` 拷到你使用的 Agent 的 skill 目录，目录名与 kebab-case `name` 相同。以玄幻为例，建立目录 `write-xuanhuan`，在该目录里放 `SKILL.md`。

InkCraft 示例：在 `.inkcraft/skills` 下建立同名目录 `write-xuanhuan`。

只拷 `SKILL.md` 即可工作。同目录 `01`–`05` 是展开，不是前提。

体裁不明时，先用 `genres/SKILL.md`（`write-genre`）。
