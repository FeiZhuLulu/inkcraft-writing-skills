## 给人读

从 `genres/README.md` 选体裁，按 `01` 到 `05` 阅读。

## 给 Agent 用

把对应 `SKILL.md` 拷到你使用的 Agent 的 skill 目录，目录名与 kebab-case `name` 相同。以 `write-xuanhuan` 为例，在该目录里放 `SKILL.md`。

InkCraft 示例：在 `.inkcraft/skills` 下建立同名目录 `write-xuanhuan`。

只拷 `SKILL.md` 即可工作。同目录 `01`–`05` 是展开，不是前提。

体裁不明时，先用 `genres/SKILL.md`（`write-genre`）。
