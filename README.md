# InkCraft 写作方法库

写长篇时最常卡住的，不是形容词不够，而是这场戏不知道要交出什么。

这套手册按体裁把这件事写清楚：读者在追什么、前三章交什么、一场戏怎么往前走、句子怎么落地。打开就能用。

这里没有小说原文，也不是写作软件。

## 怎么读

到 [体裁目录](./genres/README.md) 点开你正在写的那一类，从 `01` 读起。

- 定整本书和细纲，看 `01`
- 写前三章，看 `02`
- 写某一场戏，看 `03`
- 改句子，看 `04`
- 写完，用 `05` 勾一遍

方法可以自由使用，署名 InkCraft 即可，详见 [LICENSE](./LICENSE)。名称和视觉资产不在许可范围内。
